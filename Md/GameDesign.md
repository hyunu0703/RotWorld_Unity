# RotWorld — 게임 기획서

제작 엔진은 Unity다. 대상 플랫폼과 Unity 세부 구성은 미정이다.

## 1. 게임의 방향

RotWorld는 Unity로 제작하는 현대 도시 배경의 자율 생존 시뮬레이션 게임이다. 전체적인 그래픽과 대부분의 기능은 WorldBox를 주된 참고 기준으로 삼는다. WorldBox처럼 낮은 해상도의 픽셀 아트와 탑다운 시점, 작은 인물과 조밀한 지형으로 세계를 표현한다.

핵심 루프는 **시드 기반 전체 맵 생성 → 캐릭터 스탯·성격·특성 설정 → 자율 생존 시작 → 생존 일차 누적과 결과 관찰**이다. 맵을 먼저 생성한 뒤 프로젝트 좀보이드처럼 메인 캐릭터의 스탯과 특성을 설정한다. 성격 설정과 세부 포인트 규칙은 캐릭터 생성 기획을 따른다.

생존이 시작되면 메인 캐릭터를 포함한 인간들은 욕구를 바탕으로 자율 AI 판단을 내린다. 허기·갈증·피로·공포와 능력·성격·특성, 개인이 알고 있는 위험·물자를 함께 고려해 이동·탐색·섭취·휴식·수면·도주·전투를 스스로 선택한다. 플레이어의 반복적인 명령 없이 생존 시뮬레이션이 자동으로 이어진다.

게임 시간의 흐름에 따라 1일차, 2일차, … n일차로 생존 일차가 누적된다. 플레이어는 인물별 선택과 상태 변화, 물자 고갈과 좀비 위협이 생존에 미치는 결과를 관찰한다. 일차 표시의 첫날 기준과 날짜 전환 시각은 미정이다.

세계는 좀비 사태가 이미 시작된 현대 도시다. 초기 인간 30~50명의 작은 동네를 기본 규모로 두며, 초기 좀비 수·피해 규모·사태 발생 후 경과 시간은 미정이다. 물자 고갈·소음·전투·감염·기억과 학습은 이 세계의 자율 생존을 구성한다.

인간 빙의와 직접 행동 선택은 선택 기능으로 유지한다. 기본 진행은 자율 생존이며, 플레이어는 원할 때 개입하고 빙의를 해제하면 해당 인간은 자율 AI로 복귀한다. 빙의하지 않아도 핵심 생존 흐름이 진행된다.

### 참고 게임과 적용 범위

- WorldBox: 전체적인 저해상도 픽셀 아트, 시드 기반 전체 맵 생성, 자율적으로 움직이는 세계의 관찰과 대부분의 기능에 대한 주된 참고 기준.
- 프로젝트 좀보이드: 맵 생성 후의 캐릭터 스탯·특성 설정과 생존의 긴장감.
- 배경·인물·건물·인터페이스는 RotWorld의 현대 도시와 좀비 생존에 맞춘다. WorldBox의 모든 개별 기능을 일괄 확정하는 것은 아니며, 개별 시스템의 구체적인 규칙은 해당 기획을 따른다.

### 시드 기반 전체 맵 생성

회차 시작 시 시드를 기준으로 전체 맵을 생성한다. 맵 생성이 끝난 뒤 캐릭터 설정으로 넘어가며, 설정을 마친 캐릭터가 생성된 세계에서 자율 생존을 시작한다.

맵의 구체적인 생성 요소와 배치 규칙, 시드 입력·선택 방식, 같은 시드로 재현되는 요소의 범위는 미정이다. 현대 도시의 건물·도로와 물자·인물·좀비의 세부 배치 규칙도 각 시스템의 기획을 따른다.

## 2. 설계 원칙

- 시민은 단순한 시각적 장식이 아니라 지속적으로 상태를 유지하는 개별 인물이다.
- 자율적인 판단은 정보창을 통해 이해할 수 있어야 한다.
- 시민은 플레이어의 전지적 지식이 아니라 자신의 관찰, 기억과 학습한 정보에 따라 행동한다.
- 물품은 기존 잔여 재고를 탐색·획득·보관·소비하며 실제 수량을 유지한다. 생산과 배송은 없다.
- 인간의 자율 행동은 좀비 사태 속 안전과 생존을 중심으로 한다.
- 플레이어는 관찰하고, 명령하고, 판단 기준을 변경할 수 있다.
- 경험과 학습은 이후 행동을 바꿀 수 있다.

## 3. 동네와 건물

집, 마트, 편의점, 회사, 공장 등 다양한 현대 건물이 있는 배경으로 합의했다. 아래 목록은 논의한 건물 구성안이며, 정확한 수와 배치는 조정할 수 있다.

| 건물 | 사태 이후 주요 용도 | 위험과 제약 |
| --- | --- | --- |
| 주택·아파트 | 수면, 휴식, 식사, 비축품 보관과 은신 | 안전 여부를 확인해야 하며 비축품은 소모됨 |
| 편의점 | 남은 음식·생필품 탐색과 확보 | 재고 고갈과 좀비 접근 |
| 마트 | 남은 대량 물자 탐색 | 물자 확보 경쟁과 군중 소음 |
| 회사 | 잔여 물품 탐색과 임시 대피 | 출근·급여 기능 없음 |
| 공장 | 기존 창고·도구 탐색과 임시 대피 | 생산·출고·배송 기능 없음 |
| 식당 | 남은 식량 탐색과 임시 대피 | 음식과 안전한 공간이 제한됨 |
| 의원·약국 | 남은 약품 확보와 일반 부상 치료 장소 | 치료 조건은 미정이며 감염 치료를 보장하지 않음 |
| 공원 | 산책, 휴식, 만남 | 개방된 이동 공간이지만 은폐할 곳은 적음 |
| 도로·인도 | 생존자의 이동과 탈출 경로 | 좀비와 소음 때문에 우회할 수 있음 |

문, 출입 조건, 수용 인원, 내부 공간, 영업시간과 내부 묘사 수준은 미정이다. 지붕을 숨겨 내부 인물을 볼 수 있는 간소화된 실내 표현은 제안이며 아직 확정하지 않았다.

## 4. 개별 인간

### 확정된 신상·생활 정보

모든 인간은 이름, 나이, 사태 이전 직업, 기존 집, 돈, 소지품과 성격을 가진다. 직업과 돈은 인물 정보로 유지하되 정기 출근·급여·정상 구매의 필수 조건으로 사용하지 않는다. 교환이나 거래의 도입 여부는 미정이다. 기존 집이 안전한 거처라는 보장은 없다.

### 인간 생존 상태 — 초기 밸런스 v0.1

**아래 수치는 초기 기획 기준이다.** 허기·갈증·피로·공포는 모두 0~100이며 높을수록 불리하다. 계산은 소수로 유지하고 범위를 벗어나지 않게 제한한다.

#### 기본값과 시간 기준

| 상태 | 메인 캐릭터 시작값 | 의미 |
| --- | ---: | --- |
| 허기 | 20 | 약한 허기 |
| 갈증 | 15 | 당장 위험하지 않은 갈증 |
| 피로 | 10 | 활동 가능한 상태 |
| 공포 | 10 | 재난 상황의 긴장 |

일반 인간도 같은 변화·불이익 규칙을 사용한다. NPC의 시작값 분포는 미정이다. 모든 시간은 게임 속 시간으로 계산하며 일시정지 중에는 변화하지 않고 배속에 비례한다. 실제 시간과 게임 시간의 비율은 미정이다. 시간당 변화는 실제 경과한 게임 시간에 비례하며 화면 갱신 횟수에 의존하지 않는다.

안전은 별도 소모 게이지가 아니라 현재 위치·인지한 위협·탈출 경로를 바탕으로 평가하는 위험도다. 공포는 심리 상태, 위험도는 상황 평가로 구분한다. 피로는 장기 누적 상태이고 스태미나는 달리기·공격 등에 사용하는 단기 자원이다.

#### 허기 — 식량 확보의 필요

| 상황 | 변화 |
| --- | --- |
| 깨어 있음 | 시간당 +4 |
| 수면 | 시간당 +2, 깨어 있을 때 증가와 중복하지 않음 |
| 달리기·전투 | 깨어 있을 때 기본 증가에 시간당 +2 추가 |
| 간식 섭취 | −15 |
| 일반 식사 섭취 | −35 |

달리기와 전투의 추가량은 동시에 수행해도 한 번만 적용한다. 소식가는 총 증가량 ×0.85, 대식가는 ×1.20이며 음식의 감소량에는 적용하지 않는다. 소비 시 실제 물품을 차감한다. 허기는 0 아래로 내려가지 않으며 초과 섭취 효과를 포만감으로 저장하지 않는다.

| 허기 | 행동 영향 | 수행 불이익 |
| --- | --- | --- |
| 0~39 | 다른 활동 우선 가능 | 없음 |
| 40~59 | 다음 계획에 식량 확보 포함 | 없음 |
| 60~79 | 식사·식량 탐색 우선순위 증가 | 스태미나 회복 −10% |
| 80~99 | 식량 확보가 매우 중요 | 근접 피해 −10%, 스태미나 회복 −25% |
| 100 | 굶주림 경고·긴급 해결 | 80~99 효과 유지, 지속 피해는 전투·감염 초기값 적용 |

#### 갈증 — 수분 확보의 필요

| 상황 | 변화 |
| --- | --- |
| 깨어 있음 | 시간당 +6 |
| 수면 | 시간당 +3, 깨어 있을 때 증가와 중복하지 않음 |
| 달리기·전투 | 기본 증가에 시간당 +4 추가. 동시 수행해도 한 번만 추가 |
| 생수 1회분 섭취 | −40, 실제 물품 차감 |

| 갈증 | 행동 영향 | 수행 불이익 |
| --- | --- | --- |
| 0~39 | 물 확보의 긴급도가 낮음 | 없음 |
| 40~59 | 물 확보·비축 고려 | 없음 |
| 60~79 | 수분 섭취 우선순위 증가 | 스태미나 회복 −15% |
| 80~99 | 물 확보가 매우 중요 | 물품 취급 시간 +15%, 스태미나 회복 −30% |
| 100 | 탈수 경고·긴급 해결 | 80~99 효과 유지, 지속 피해는 전투·감염 초기값 적용 |

허기·갈증 100이 즉사를 뜻하지 않는다. 탈수의 지속 피해를 굶주림보다 강하게 두는 방향이며, 승인된 지속 피해·회복·사망 기준은 전투·감염 초기 규칙 절을 따른다. 음식·물의 규격은 [Items.md](Items.md)를 따른다.

#### 피로 — 활동과 수면의 균형

| 상황 | 변화 |
| --- | --- |
| 깨어 있음 | 시간당 +4 |
| 달리기·전투 | 기본 증가에 시간당 +3 추가. 동시 수행해도 한 번만 추가 |
| 앉아서 휴식 | 기본 피로 증가 중단. 피로를 낮춰 수면을 대체하지는 않음 |
| 안전한 곳에서 수면 | 시간당 −10, 깨어 있을 때 증가 미적용 |

휴식 중 스태미나 회복량은 아래 내부 기준을 따른다. 적은 수면은 수면 회복 속도를 ×1.25로 하여 시간당 −12.5, 많은 수면은 ×0.80으로 하여 시간당 −8로 한다. 피로 80을 0까지 회복하면 각각 기본 8시간·적은 수면 6.4시간·많은 수면 10시간이다. 이는 회복량 비교 예시이며 AI의 수면 종료 목표는 아래 행동 기준을 따른다.

| 피로 | 행동 영향 | 수행 불이익 |
| --- | --- | --- |
| 0~39 | 일반 활동 | 없음 |
| 40~59 | 장거리 탐색보다 거처 복귀·휴식 고려 | 없음 |
| 60~79 | 안전한 수면 장소 확보 우선 | 최대 스태미나 −15%, 물품 취급 시간 +10% |
| 80~99 | 수면 강하게 선호 | 최대 스태미나 −30%, 물품 취급 시간 +25%, 회피 −5%p |
| 100 | 탈진, 안전한 곳에서 수면 최우선 고려 | 80~99 효과 유지. 초기 버전에 강제 기절 없음 |

#### 공포 — 인지한 사건과 환경에 대한 반응

공포는 시간만으로 일정하게 쌓이지 않는다. 인간이 직접 인지한 위협과 환경에 반응하며 화면 밖 좀비의 실제 위치를 근거 없이 사용하지 않는다.

| 원인·상황 | 변화 |
| --- | --- |
| 새로운 좀비 위협 발견 | 사건당 +10 |
| 가까이에서 추적당함 | 게임 시간 1분당 +4 |
| 추가 좀비에게 포위됨 | 추적 증가량을 +6/분으로 대체. +4와 합산하지 않음 |
| 공격받음 | 사건당 +15 |
| 어두운 장소 체류 | +1/분, 이 원인만으로는 40까지 |
| 위험 해소 후 위협을 감지하지 않음 | 5분간 위협 없음이 유지된 뒤 −3/분 |

같은 좀비를 매 갱신마다 새로 발견한 것으로 계산하지 않는다. 잠깐 시야에서 사라졌다 재등장해도 발견 공포를 반복 지급하지 않도록 사건을 구분한다. 새 위협 사건의 구체적인 재판정 조건은 미정이다. 위협을 다시 인지하면 안전 회복 대기는 다시 시작한다. 어둠 등 지속 환경 원인과 안전 회복의 동시 적용 여부·순서는 미정 사항이다.

어둠에 익숙함은 어둠 증가량을 +0.6/분으로 줄인다. 폐쇄 공간 공포는 기존 특성대로 게임 시간 10분당 +5이며 그 원인만으로는 40까지 올린다. 이미 40 이상이면 해당 제한 원인은 추가 상승시키지 않지만 추적·피격 등은 40을 넘길 수 있다.

| 공포 | 자율 행동 영향 | 수행 불이익 |
| --- | --- | --- |
| 0~39 | 기존 판단 유지 | 없음 |
| 40~59 | 위험 탐색·불필요한 전투를 덜 선호 | 없음 |
| 60~79 | 도주·은신 선호 증가 | 공격 명중 −10%p, 물품 취급 시간 +10% |
| 80~100 | 탈출 강하게 선호 | 공격 명중 −20%p, 물품 취급 시간 +25% |

침착성은 공포 수치가 아닌 공포의 수행 불이익 크기에 적용한다. 스탯 8이면 위 명중 −20%p는 −15.2%p, 취급 시간 +25%는 +19%가 된다. 직접 조작 중에도 수행 불이익을 적용하지만 자동 도주·비명·명령 취소를 강제하지 않는다. 자율 경고는 개인의 지식과 상황에 따라 선택한다.

#### 상태 효과의 중첩

- 구간은 0 이상 40 미만, 40 이상 60 미만, 60 이상 80 미만, 80 이상 100 미만, 100으로 해석한다. 공포의 마지막 구간은 80 이상 100 이하다. 각 상태의 구간별 효과는 해당 구간 하나만 적용한다.
- 허기·갈증의 스태미나 회복 감소는 더 강한 값만 적용한다. 둘 다 80 이상이어도 감소는 −30%다.
- 물품 취급 시간의 상태 증가분은 합산하되 최대 +50%다. 공포분은 침착성으로 보정한 후 합산한다. 이후 정리 습관·서투른 손놀림의 배율을 곱한다.
- 예: 침착성 5에서 피로와 공포의 취급 시간 증가가 각각 +25%이면 기본 10초가 15초다. 정리 습관이 있으면 12초다. 갈증까지 나빠져도 상태 증가 상한은 +50%다.
- 지구력으로 정한 최대 스태미나에 피로의 감소 배율을 적용한다. 명중·회피는 상태 보정 후 최종 확률 상·하한을 따르며 구체적인 전투 기준은 미정이다.

#### AI의 욕구 해결 시작과 종료

**즉각적인 위험 대응 → 긴급한 생존 욕구 해결 → 향후 물자·거처 확보 → 여유 행동**을 기본 흐름으로 둔다. 위험 중에는 배고프다는 이유만으로 식사를 시작하지 않는다.

| 해결 행동 | 시작 기준 | 해결 목표 |
| --- | --- | --- |
| 식사·식량 탐색 | 허기 60 이상 | 허기 35 이하 |
| 수분 섭취·물 탐색 | 갈증 60 이상 | 갈증 30 이하 |
| 수면 장소 탐색·수면 | 피로 60 이상 | 피로 20 이하 |

시작과 종료 기준을 다르게 두어 경계에서 행동을 반복 변경하지 않게 한다. 40~59의 계획 행동이나 비축 성향은 긴급 해결 전에 준비할 수 있게 한다. 보유 물자로 목표에 도달하지 못하면 안전·재고·해결 시간을 비교해 추가 행동을 선택한다. 여러 욕구가 겹칠 때도 숫자만 비교하지 않고 가진 물품·해결 시간·경로 위험을 함께 고려한다. 위험 발생 시 재평가한다. 직접 조작에서는 이 기준이 플레이어의 행동을 강제하지 않는다.

#### 체력·스태미나의 내부 기준

**초기 밸런스다.**

| 항목 | 승인된 초기 기준 |
| --- | --- |
| 체력 | 내부 현재·최대 100으로 시작. 피해·회복·사망은 전투·감염 초기 규칙을 따름 |
| 스태미나 | 기본 최대 100. 지구력 5 기준, 1점당 최대치 ±6%. 생성 시 지구력을 반영한 최대치로 시작 |
| 피로 보정 | 피로 60 이상 80 미만은 최대 스태미나 ×0.85, 80 이상은 ×0.70 |
| 걷기·물품 취급 | 게임 1분당 각각 −1·−2. 실제 행동 시간만 적용하며 중단 전 사용한 힘은 반환하지 않음 |
| 대기·섭취·휴식·수면 | 게임 1분당 각각 +6·+6·+12·+18. 수면 특성은 기존 피로 회복만 바꾸며 스태미나 회복률은 바꾸지 않음 |
| 회복 보정 | 기존 허기·갈증 표의 회복 감소 중 강한 값만 적용. 소모량에는 적용하지 않음 |
| 최대치 변경 | 줄면 현재량을 최대치 이내로 제한. 늘어도 현재량을 자동 충전하거나 비율로 복구하지 않음. 최대치 변경만으로 회복·소모 중이라고 표시하지 않음 |
| 행동 가능 여부 | 스태미나 0에서도 현재 기본 걷기·획득·보관·섭취·휴식·수면을 차단하지 않음. 전투 비용은 전투 초기 규칙을 따르며 달리기 비용은 미정 |

모든 시간은 게임 시간이며 정지·배속·행동 전환에 연동한다. 욕구·피로의 보정 경계를 지날 때 구간을 나눠 계산한다. 내부 수치·최댓값·비율·숫자 증감은 플레이어 화면에 노출하지 않고 아래 텍스트 규칙을 따른다.

피로 40 이상 60 미만에서는 직접 확인한 수면 거점을 거리·알려진 위험으로 비교해 장거리 탐색보다 복귀·휴식을 고려한다. 욕구 점수와 이동·위험 비용을 함께 고려하는 기본안이다. 입구에 도착하면 앉아서 쉬며 피로 60 전에는 자율 수면을 시작하지 않는다. 긴급 식량·물 해결과 위험 대응을 우선하며 복귀 중에도 전환할 수 있다. 모르는 수면 거점을 미리 사용하지 않으며 아는 거점이 없으면 기존 탐색을 유지한다. 피로 60부터 수면 해결을 시작하고 자율 종료 목표 20은 유지한다. 휴식은 피로를 줄이지 않는다.

정보창은 신체·활동 여력 요약, 일시정지 중단 안내, 행동별 소모·회복 원인, 지구력·피로의 최대치 보정과 강한 허기·갈증 회복 저하만 적용된다는 사실을 설명한다. 물품 취급은 갈증·피로·침착성 보정 후 공포의 증가분, +50% 상한, 특성 배율과 최종 배율을 따로 설명한다. 진행 중 작업에는 시작 당시 보정의 복사본을 표시하고 다음 작업 기준과 구분한다. 체력·스태미나의 현재량·최대량·비율은 이 설명에도 노출하지 않는다.

신체·활동 여력 단계는 회복 전환 여유 3%p와 큰 변화·바닥 이탈 규칙을 적용하고 인물 상태에 보존한다. 위중 진입·사망 확정·힘이 바닥남 사건은 별도 텍스트 알림과 도시 기록에 전달하며 같은 상태의 반복 알림은 억제한다. 정보창의 최근 중요 상태 변화는 최대 8건을 보관하는 UI 기본안이다.

#### 체력·스태미나의 텍스트 상태 표시 — 초기 밸런스 v0.1

**표시 문구와 아래 내부 구간은 초기 기획 기준이다.** 내부 수치는 계산에 유지하지만 플레이어의 기본 화면·상세창·툴팁·신의 조정 화면에는 체력·스태미나 현재값·최댓값·백분율을 표시하지 않는다. 비율을 드러내는 게이지와 숫자 증감 팝업도 사용하지 않는다. 플레이 중 조정이 필요하면 회복·악화 같은 텍스트 명령을 제공한다.

허기·갈증·피로·공포, 캐릭터 생성 스탯과 감염 남은 시간의 숫자 표시까지 제거하는 것은 아니다. 이 절은 표시 규칙을 정하며, 이전 대화에서 제안한 체력·스태미나 소모·회복·부상 수치 전체를 확정하는 것은 아니다.

##### 신체 상태 — 체력의 표시

내부 비율 H는 `현재 체력 ÷ 최대 체력 ×100`이다. 반올림 전 값을 사용한다. 아래는 최초 표시와 악화 시의 기본 구간이다.

| 내부 구간 | 표시 문구 | 설명 |
| --- | --- | --- |
| 80 < H ≤ 100 | 양호 | 전반적인 신체 손상이 적다. 부상·감염 없음이나 완치라는 뜻은 아님 |
| 60 < H ≤ 80 | 경미한 손상 | 다쳤지만 활동할 수 있다 |
| 30 < H ≤ 60 | 상당한 손상 | 추가 피해를 경계하고 치료해야 한다 |
| 0 < H ≤ 30 | 위중 | 생명이 위험하며 안전 확보와 치료가 시급하다 |
| H = 0, 사망 확정 | 사망 | 생존 활동이 끝났다 |

체력 0은 즉시 사망이며 빈사·소생은 기본 범위에 포함하지 않는다. 사망 표시는 사망 판정을 따른다. 사망 상태에서 자동으로 회복 문구로 돌아가지 않는다.

일반 상처·출혈·물린 상처·감염은 체력 단계와 별도로 표시한다. 높은 체력이어도 부상이 남아 있을 수 있다.

##### 활동 여력 — 스태미나의 표시

내부 비율 S는 `현재 스태미나 ÷ 피로 등 보정을 반영한 현재 최대 스태미나 ×100`이다. 현재 최대치는 양수여야 하며 현재량을 0~최대치로 제한한다.

| 내부 구간 | 표시 문구 | 설명 |
| --- | --- | --- |
| 75 < S ≤ 100 | 여유 있음 | 현재 감당할 수 있는 활동 여력이 충분하다 |
| 50 < S ≤ 75 | 숨이 차오름 | 활동을 이어갈 수 있지만 소모에 주의해야 한다 |
| 20 < S ≤ 50 | 숨이 가쁨 | 격한 행동을 이어가면 힘이 부족해질 수 있다 |
| 0 < S ≤ 20 | 기진맥진 | 격한 행동을 지속하기 어렵다 |
| S = 0 | 힘이 바닥남 | 휴식이 필요하다 |

위 설명은 상태 수준을 뜻하며 현재 회복·소모 여부는 아래 변화 방향을 따른다. 피로는 장기적인 수면 필요, 활동 여력은 단기적인 힘으로 구분한다. 피로 때문에 최대 스태미나가 낮으면 여유 있음이어도 오래 활동하지 못할 수 있으므로 관련 원인을 상세 설명에 함께 표시한다.

##### 변화 방향·원인·행동 안내

| 대상 | 순변화가 양수 | 순변화가 없음 | 순변화가 음수 |
| --- | --- | --- | --- |
| 신체 상태 | 회복 중 | 안정됨 | 악화 중 |
| 활동 여력 | 회복 중 | 유지 중 | 소모 중 |

변화 방향은 비율 변화가 아니라 실제 체력·스태미나의 합산된 현재 증감 원인과 순변화로 결정한다. 최대치만 바뀐 것을 회복·소모로 표현하지 않는다. 일시정지 중에는 진행 중인 것처럼 표시하지 않고 상세 정보에서 중단을 알린다. 사망에는 변화 방향을 붙이지 않는다. 순간 피격은 즉시 사건 알림으로 전달하고, 이후에도 감소가 지속하는지는 실제 규칙에 따른다. 0에 도달해 더 줄지 않는 경우에도 출혈·소모 시도 등 지속 원인은 별도로 알린다.

표현은 `요약 상태 · 변화 방향`을 기본으로 하고 상세창에서 확인된 원인, 부상과 대처를 보여준다. 안정됨은 안전·완치를 보장하지 않는다. 존재하지 않는 치료 조건이나 캐릭터가 모르는 사실을 설명 문구로 만들어내지 않는다.

> 신체: 상당한 손상 · 악화 중
>
> 출혈이 계속되고 있다. 상처 처치가 필요하다.
>
> 활동 여력: 숨이 가쁨 · 회복 중
>
> 갈증 때문에 회복이 더디다.

이 예시는 관련 출혈·회복 조건을 충족할 때 사용한다. 숫자 피해량, 남은 공격 횟수와 정확한 사망까지의 시간은 노출하지 않는다.

행동 가능 여부는 단계명과 별도로 실제 요구량·조건으로 판정한다. 예: `공격 가능`, `무거운 공격 불가 — 힘이 부족하다`. 여유 있음만으로 모든 행동 가능을 보장하지 않는다. 표현을 위해 행동을 임의로 차단하지 않는다.

##### 경계 전환과 알림

- 최초 표시에서는 기본 구간을 적용한다. 악화 시에는 해당 경계를 넘는 즉시 반영하고 한 번의 큰 피해로 여러 단계를 건너뛰면 실제 구간으로 바로 이동한다.
- 회복 시에는 일반 경계보다 3%p 더 회복해야 한 단계 좋은 문구로 바꾼다. 체력은 위중에서 상당한 손상으로 H ≥33, 경미한 손상으로 H ≥63, 양호로 H ≥83에서 전환한다. 스태미나는 기진맥진에서 숨이 가쁨으로 S ≥23, 숨이 차오름으로 S ≥53, 여유 있음으로 S ≥78에서 전환한다. 큰 회복이면 조건을 만족하는 단계까지 바로 전환한다.
- 회복 대기 구간에서 작은 증감은 문구를 유지한다. 예: H 31에서는 위중을 유지하고 회복 중을 표시하며, H 33에서 상당한 손상으로 바뀐다. 이 표시 여유는 실제 피해·불이익·행동 판정에 적용하지 않는다.
- 힘이 바닥남은 S >0이 되면 즉시 기본 구간으로 벗어난다. 아직 행동 비용이 부족하면 행동 버튼에서 이유를 알려준다. S =0과 사망, 위중 진입은 지연하지 않는다.
- 재시작·불러오기에서 상태가 튀지 않도록 표시 단계도 보존하는 것을 초기 기준으로 한다.
- 위중 진입·출혈 시작 등 중요한 변화는 즉시 별도 알림을 제공한다. 같은 조건의 반복 알림은 억제하고 단계 악화나 새로운 원인 발생 시 다시 알린다. 색상·아이콘은 보조이며 텍스트만으로도 구분할 수 있어야 한다.

#### 상태 확인과 남은 설계

인간 정보창은 생존 상태, 변화 원인, 적용 중인 불이익과 행동 선택 이유를 보여준다. 체력·스태미나는 위 텍스트 표시 규칙을 따르며 다른 상태의 기존 표시 범위는 유지한다. 위험도와 공포는 구분한다.

지속 피해량·사망·전투 비용의 승인 초기값은 전투·감염 초기 규칙 절을 따른다. 미정: 일반 NPC 시작값, 최종 시간 배율, 달리기 스태미나 비용, 안전한 수면 조건·중단·위험 시 각성, 공포 원인 중첩·안전 회복 동시 적용, 근거리 추적·어둠 판정과 새 위협 재판정 조건.

### 자율 치료와 회복 아이템 확보

회복 아이템이 없으면 수색을 통해 확보한다. 붕대는 보유 2개부터 붕대만을 목적으로 추가 수색하지 않는다. 전체 회복 아이템 합계가 5개 이상이면 회복 아이템만을 목적으로 추가 수색하지 않는다. 붕대도 전체 합계에 포함한다. 목표 수량은 전용 수색을 멈추는 기준이며 소지 자체의 상한은 아니다. 0개 초과·목표 미만일 때의 추가 수색 기준과 붕대 외 회복 아이템별 목표는 미정이다.

다른 수색 도중 회복 아이템을 발견하면 확보 후보로 판단한다. 다만 더 우선하는 아이템을 수색 중이면 회복 아이템을 가져가지 않는다. 소지 한도와 현재 필요도를 함께 고려한다. 붕대는 출혈 중인 상처에 사용하며 실제 지혈 방법은 아이템 규칙을 따른다. 위험 대응·실제 지혈·다른 긴급 욕구 간 세부 우선순위는 미정이다.

### 아이템 출현 규칙

간식·식사·물·붕대·쇠파이프는 특정 건물에만 제한하지 않으며 모든 건물에서 구할 수 있다. 무기는 지정된 특정 이름 건물에서 출현할 확률이 매우 높고 다른 건물에서는 매우 낮다. 특정 이름 건물 전용 출현으로 제한하지 않는다. 정확한 확률·수량과 무기별 고확률 건물 이름은 미정이다. 가방의 출현 범위·확률은 미정이다.

### 소지 한도와 수색 우선순위

기본 소지 한도는 8개다. 가방 아이템을 구하면 총 소지 한도가 24개로 확장된다. 음식·물 1회분은 1개로 계산한다. 한도가 찼다면 현재 필요한 아이템의 우선순위를 비교해 해당 수색을 하지 않거나 가장 필요 없는 소지품을 버려 수량을 줄인 뒤 필요한 아이템을 확보한다. 일률적인 고정 순위가 아닌 현재 상태에 따른 판단이며 세부 점수·동률 기준은 미정이다. 버린 물품의 지면 보존·재획득 규칙은 미정이다.

### 자율 생존 복귀

빙의가 끝나면 빙의 전에 수행하던 행동·목표·우선순위를 복원하지 않는다. 종료 시점의 몸 상태·욕구·소지품·인지한 위험을 기준으로 우선순위를 새로 판단하고 자율 AI로 행동한다. 이는 이전 행동 계획을 재개하지 않는다는 의미이며, 개인이 관찰한 장소·위험·학습 지식의 삭제 여부와 빙의 중 정보 습득 범위는 미정이다. 직접 명령 종료 후 자율 생존으로 복귀할 때도 복귀 시점의 상태로 재판단한다. 직접 명령의 구체적인 종료·취소 조건은 미정이다.

### 욕구와 자율 행동

시민은 위 인간 생존 상태의 허기·갈증·피로·공포와 현재 위험도에 따라 행동을 선택한다. 상태 수치는 초기 밸런스 v0.1을 따른다. 안전은 별도 소모 게이지로 두지 않는다.

인간의 행동 알고리즘은 출근·돈 벌기·쇼핑 중심에서 생존 중심으로 변경한다. 확정 방향은 안전 확보, 남은 물자 탐색·획득, 식사·수분 섭취, 휴식·수면, 은신, 도주와 전투다.

제안하는 판단 흐름은 다음과 같다. 실제 점수와 우선순위 수치는 미정이다.

1. 인지한 좀비, 부상, 포위와 탈출 경로 등 즉각적인 위험을 평가한다.
2. 능력·성격·소지품·몸 상태에 따라 도주, 은신 또는 전투를 선택한다.
3. 긴급 위험이 낮으면 허기·갈증·피로와 보유 물자를 비교한다.
4. 가진 물품으로 욕구를 해결하거나, 알고 있는 물자 장소와 안전한 휴식 장소를 탐색한다.
5. 거리, 예상 소음, 알려진 위험, 물자 기억과 성격을 비교해 목적지를 선택한다.
6. 상황 변화, 목적지 도착, 재고 고갈이나 새로운 위험 발생 시 다시 판단하고 근거를 기록한다.

빙의 중인 인간은 플레이어가 행동을 선택한다. 다른 인간은 자율 판단을 유지한다. 자동 긴급 회피와 플레이어 선택의 충돌 규칙은 10절과 11절의 미정 사항을 따른다.

정보는 지역적이고 개인별로 관리한다. 알지 못하는 위험이나 목격하지 않은 재고 변화가 모든 시민에게 자동으로 전달되어서는 안 된다.

### 정보 확인

인간을 클릭하면 신상 정보, 집, 직업, 돈, 소지품, 성격, 현재 욕구, 현재 행동과 선택 이유를 보여준다. 능력, 학습한 지식과 감염 정보도 표시한다.

판단 설명은 실제 근거를 반영해야 한다. 예: 식량이 없고 허기가 높아, 남은 재고가 있다고 기억하며 위험이 상대적으로 낮은 편의점을 탐색한다. 플레이어가 선택한 행동은 자율 AI 판단과 구분해 표시한다.

## 5. 잔여 물자 탐색·획득·소비

물자는 생산되지 않으며 공장·매장 사이의 배송과 물류 운반도 발생하지 않는다. 기존 생산·배송 경제 기획은 폐기한다.

현재 물자 흐름은 `세계에 남아 있는 재고 → 탐색·획득 → 인간의 소지품·거처 보관 → 사용·소비`다. 획득 시 원래 장소의 재고가 줄고, 소비 시 해당 물품이 사라진다. 자동 재입고나 자연 재생산은 기본 규칙에 포함하지 않는다.

인간이 확보한 물건을 소지하고 이동하거나 거처에 보관하는 것은 생존 행동의 기본안으로 유지한다. 이는 폐기한 생산·배송망과 구분한다. 개인 소지품의 이동과 버리기를 허용한다.

가게는 정상 판매·결제 대신 남은 물자를 탐색하는 장소다. 허기·공포·성격·위험과 타인의 소유 여부에 따라 가져갈지를 판단한다. 소유권, 공유와 생존자 간 거래는 미정이다.

기존 아이템의 종류·초기 수량·배치는 [Items.md](Items.md)를 따른다. 기본 소지 한도는 8개이며 가방 확보 시 총 24개다. 추가 아이템의 세부 규격은 미정이다. 건물 정보창에는 잔여 재고, 탐색 가능 여부와 인지한 위험 등을 표시하는 안을 제안한다.

## 6. 좀비와 소음

좀비는 자율적으로 돌아다니며 소음에 민감하다. 소리는 판단에 영향을 주고 특정 위치를 수색하거나 인간을 추적하도록 유도할 수 있다.

소음원에는 생존자의 이동·탐색, 목소리, 비명, 외치는 경고와 물건 파손 등이 포함된다. 소리 전파, 장애물에 의한 차단, 감쇠와 목표 선택 방식은 미정이다.

플레이어는 좀비의 소음 민감도와 이동 속도를 조정할 수 있다. 청각 범위와 추적 지속 시간은 추가 조정 항목으로 제안했다. 민감도는 소리의 강도에 얼마나 반응하는지를, 청각 범위는 얼마나 멀리서 감지하는지를 뜻한다.

## 7. 인간의 전투와 도주

인간은 좀비와 마주치면 도망가거나 공격할 수 있다. 맨손으로 싸우거나 소지품 중 공격 가능한 물건을 사용할 수 있다.

판단에는 능력, 성격, 몸 상태, 공포, 사용 가능한 물건, 좀비 수와 거리, 탈출 가능성을 고려한다. 상황이 변하면 다시 판단하며, 싸움을 멈추고 도주할 수 있다.

싸운다고 반드시 물리는 것은 아니다. 물리지 않고 좀비를 쓰러뜨리거나, 공격을 피하거나 막거나, 도망치거나, 일반 부상을 입거나, 물릴 수 있다. 결과는 인간의 능력과 좀비를 포함한 교전 상황에 따라 달라진다.

기본 스탯은 근력·민첩·지구력·지각·침착성·학습력이며 전투 숙련은 별도로 관리한다. 무기의 사거리, 위력, 상태와 관련 숙련도도 고려 요소로 제안했다. 계산식, 판정 시점, 무기 종류, 내구도와 균형은 미정이다.

공격 성공, 반격과 물림 결과를 구분할 수 있어야 한다. 일반적인 전투 부상이 자동으로 감염을 뜻하지는 않는다. 합의된 감염 조건은 좀비의 물림 성공이다.

정보창은 전투와 도주 판단을 설명해야 한다. 직접 명령에는 공격이 포함되며, 플레이어는 관련 인간 수치를 조정할 수 있다.

## 8. 감염과 변이

좀비에게 물리면 감염되고, 게임 속 일정 시간이 지나면 좀비로 변한다.

| 단계 | 인간의 상태 | 주변 시민의 인식 |
| --- | --- | --- |
| 잠복기 | 감염됐지만 눈에 보이는 증상이 없음 | 감염 사실을 자동으로 알지 못함 |
| 증상기 | 관찰 가능한 증상이 나타남 | 증상을 인지한 시민이 의심하고 피할 수 있음 |
| 변이 | 인간이 좀비로 바뀜 | 목격자는 좀비의 위협에 반응 |

플레이어는 항상 감염 상태와 변이까지 남은 시간을 확인할 수 있다. 주변 시민에게는 이 정보가 주어지지 않는다. 증상을 인지해야 의심이 생기며, 먼 곳의 시민이 자동으로 알아서는 안 된다.

시간 처리는 시뮬레이션 시간을 기준으로 하며, 일시정지와 배속은 감염 진행에도 영향을 준다. 감염은 최초 물림 후 잠복기 최소 10분·증상 시작 30분·변이 1시간의 승인 초기 규칙을 따른다. 변이 후에도 원래 이름과 이력을 유지하는 방식을 제안했다.

첫 버전은 감염 치료제 없음·체력 0 즉시 사망으로 정했다. 상세 범위는 전투·감염 초기 규칙 절을 따른다. 의원이 있다고 해서 감염 치료 기능이 확정된 것은 아니다.

### 전투·감염 초기 규칙·수치

**초기 밸런스다.** 모든 시간은 게임 시간이다. 체력·스태미나는 내부 계산에 사용하고 플레이어에게는 텍스트 상태로 표시한다. 아래 구체적인 규칙이 앞선 일반적인 미정 설명보다 우선한다.

#### 전투 실행과 기본 수치

공격 준비 → 타격 순간 사거리·건물 가림 확인 → 명중 → 회피 → 일반 피해 또는 물림 → 상태·AI 재평가 순서다. 접촉 자체는 공격 성공·물림이 아니다. 반격은 상대의 별도 공격이며 인간 공격에 무료 즉시 반격을 붙이지 않는다. 공격 시작 시 스태미나를 사용하고 취소해도 반환하지 않으며 재사용 대기시간을 유지한다. 같은 시각에 완성된 공격은 함께 판정한다.

| 항목 | 승인 초기값 |
| --- | --- |
| 체력 | 인간 100 유지, 좀비 60 |
| 맨손 공격 | 피해 10, 사거리 1타일, 스태미나 6 |
| 둔기 공격 | 피해 20, 사거리 1.3타일, 스태미나 8 |
| 인간 공격 주기 | 준비 3초 + 공격 후 회복 9초 = 12초 |
| 밀치기 | 피해 없음, 사거리 1타일, 스태미나 6, 주기 10초, 기본 성공률 80% |
| 밀치기 성공 | 통행 가능한 방향으로 1타일 밀고 3초 행동 지연. 벽을 통과시키지 않음 |
| 좀비 공격 | 사거리 0.8타일, 준비 4초 + 회복 11초 = 15초 |
| 좀비 피해 | 일반 타격 8, 물림 18 |

근력의 기존 피해·밀치기 위력 보정과 민첩의 공격 후 회복시간 보정을 적용한다. 벽 너머 공격·밀치기는 불가능하다. 기본 전투 범위는 맨손·둔기·밀치기다. 별도 방어 자세·총기·치명타·무기 내구도는 기본 범위에서 제외한다. 인간 걷기는 0.45타일/초, 좀비 추적은 0.3타일/초다. 달리기의 세부 규칙은 미정이다.

#### 명중·회피·물림

| 판정 | 승인 초기값 |
| --- | --- |
| 인간 명중 | 기본 80%, 최종 10~95% |
| 좀비 명중 | 기본 60%, 최종 10~95% |
| 인간 회피 | 기본 20% + 기존 민첩 보정, 최종 5~60%. 자동 판정, 별도 스태미나 비용 없음 |
| 포위 | 포위 조건 충족 시 회피 −10%p. 캐릭터가 바라보는 앞쪽과 그 반대인 뒤쪽에 좀비가 각각 1마리 이상 있을 때 충족. 한쪽에만 있으면 충족하지 않음. 거리·앞뒤 각도 경계·인지 조건은 미정 |
| 물림 | 좀비 공격 명중 후 인간 회피 실패 결과 중 10% |
| 감염 | 물림 성공 시 100% |

기본 상태의 좀비 공격 시도당 물림 확률은 60% × 80% × 10% = 4.8%다. 물림이 아닌 결과는 일반 타격이다. 인간의 맨손 공격이나 단순 접촉으로 감염되지 않는다. 기존 허기·피로·공포 불이익과 침착성의 공포 불이익 보정을 연결한다.

#### 부상·출혈·치료

부상은 전신 단위의 일반 상처·출혈·물린 상처로 구분한다. 팔·다리별 손상·골절은 기본 범위에서 제외한다. 일반 타격은 체력 피해와 일반 상처를 만들고 감염시키지 않는다.

| 항목 | 승인 초기값·조건 |
| --- | --- |
| 출혈 발생 | 일반 타격 피해 발생 시 20%, 물림 시 항상 발생 |
| 출혈 피해 | 상처 하나당 분당 0.5, 합계 최대 분당 2 |

| 일반 상처 회복 | 지혈 후 회복 조건을 충족한 누적 시간 6시간 |

붕대는 물린 상처의 출혈을 멈추지만 감염은 치료하지 않는다.

#### 체력 0·지속 피해·사망 후 처리

- 체력 0은 즉시 사망 확정이다. 초기에는 빈사·소생을 제공하지 않는다.
- 허기 100은 시간당 체력 −2, 갈증 100은 −6이며 동시에 발생하면 합산한다. 각 상태가 100 미만으로 내려가면 해당 지속 피해를 중단한다.
- NPC 사망 후 세계는 계속된다. 시신·소지품을 보존하고 복제·소실을 막는다. 시신은 보존·표시하며 약탈 규칙은 미정이다.
- 제압한 좀비는 다시 공격하지 못하는 제거 상태가 된다.
- 주인공 사망 시 회차 진행을 즉시 종료·폐기한다. 사망 원인을 보여준 뒤 생성 화면으로 돌아가며 다른 인간으로 이어가지 않는다.

잠복기 최소 10분과 증상 시작 30분은 함께 적용한다. 10~30분에 별도 증상이나 추가 단계를 만들지 않는다. 감염 시간은 정지·배속에 연동한다. 주인공이 먼저 사망하면 회차를 즉시 폐기하므로 해당 회차에서 이후 시신 재기동을 관찰하며 이어갈 수 없다.

#### 자율 전투·도주와 직접 지시

- 자발적 전투의 공통 조건: 직접 본 위협 한 마리, 출혈 없음, 내부 체력 60 초과·스태미나 40 이상·공포 60 미만.
- 공격 성향 낮음은 도주 우선, 막히면 밀치기로 탈출 시도. 보통은 무기와 안전한 퇴로가 있을 때 전투 고려, 높음은 공통 조건 충족 시 맨손 전투도 고려한다.
- 체력 40 이하, 스태미나 20 미만, 공포 80 이상, 추가 좀비 접근 또는 출혈 발생 시 전투 중단·도주를 재평가한다.
- 직접 지시 중에는 자동 도주를 강제하지 않는다. 사망·변이·대상 소멸·힘 부족은 실제 행동을 제한하고 이유를 표시한다.
- 전투 소음의 초기 기준은 맨손·밀치기 도달 범위 6타일, 둔기 타격 10타일로 전투 소음을 추가한다.

#### 전투·생존 세부 규칙

아이템 상세 규격은 [Items.md](Items.md)를 참고한다.

1. 쇠파이프 1종, 출현 건물 분류·초기 배치 수량은 [Items.md](Items.md)를 따르며 시작 소지 0개, 한도 1칸, 즉시 장착·해제·보관 시 해제. 자율 인간은 가진 무기를 장착하고 공격 성향 보통·높음은 직접 확인한 재고에서 하나까지만 확보한다.
2. 좀비 회피 없음. 인간 명중 성공 후 별도 좀비 회피 판정을 하지 않으며 사거리·건물 가림은 검사한다.
3. 밀치기는 준비 2초·회복 8초. 성공하면 승인된 거리만큼 밀고 3초 행동 지연·좀비 준비 공격 취소. 실패·밀 공간 없음에는 이동·지연 없음. 성공·실패·중단 모두 비용·대기시간 유지.
4. 실제 피해를 입힌 공격 한 번당 일반 또는 물린 상처 하나. 상처를 합치지 않는다. 각 상처의 출혈·회복 시간을 따로 저장한다. 물린 상처도 지혈 후 조건 누적 6시간에 회복하지만 감염 시계는 남는다. 지혈된 상처에는 붕대 사용 불가.
5. 전투 소음은 준비 종료 후 살아 있는 대상·사거리·가림 조건을 만족해 타격을 시도할 때 한 번 발생한다. 명중·회피·밀치기 판정 실패에도 발생하며 준비 취소·사거리 이탈·대상 사망에는 발생하지 않는다.
6. 안전한 퇴로는 개인이 관찰한 통행 지점을 잇는 길이 4~12타일 경로다. 모든 경로 지점은 기억한 좀비에서 1.5타일 이상 떨어지고 위험이 현재 위치 이하이며, 끝점 위험 20 미만·상하좌우 통행 방향 2개 이상이다. 보통 공격 성향은 이 경로가 있어야 자발적 전투를 시작하고 전투 중 게임 1초마다 다시 검사한다.
7. 공포 +15는 실제 일반 타격·물림 피해 한 번당 한 번이다. 빗나감·회피·접촉·피해 없는 밀치기·이후 출혈/굶주림/탈수에는 반복 적용하지 않는다. 서로 다른 동시 피격은 각각 적용하고 100으로 제한한다.

## 9. 경고·기억·학습

좀비 사태가 시작된 세계라도 모든 인간이 좀비의 특성을 완전히 아는 것은 아니다. 경험으로 계속 배우며, 시작 시 개인별 지식과 경험 수준은 미정이다.

- 처음에는 좀비를 본 시민이 소리쳐 경고할 수 있다.
- 경고를 들은 인간은 대피하거나 안전한 곳을 찾는다.
- 좀비도 경고 소리에 끌려온다.
- 인간은 경험을 통해 좀비가 소리에 민감하다는 사실을 배운다.
- 이 사실을 알게 되면 소리치는 경고를 중단하고 행동을 바꾼다.
- 지식은 전체에 일괄 적용하지 않고 시민별로 관리한다.

불확실한 의심에서 확신으로 발전하는 지식 모델, 반복 관찰, 대화를 통한 학습을 설계안으로 둔다. 정확한 학습 기준과 지식 공유 방식은 미정이다. 조용히 경고하는 행동은 미확정 설계안이다.

정보창은 배운 사실과 근거를 보여줘야 한다. 초기 지식 범위로 소음의 위험, 위험 장소의 기억과 물자 확보 장소를 제안했으며, 상황 변화에 따라 기억을 갱신하는 방향이다.

## 10. 신의 개입과 관찰

### 시작 전 메인 캐릭터 생성과 플레이 종료

플레이어는 시드로 전체 맵을 생성한 뒤 메인 캐릭터의 스탯, 성격과 특성을 설정한다. 설정을 마치면 생성된 세계에서 메인 캐릭터를 포함한 인간들의 자율 생존을 시작한다. 프로젝트 좀보이드는 캐릭터 설정과 사망의 무게를 참고하는 게임이며, 해당 게임의 실제 저장 규칙을 그대로 채택한다는 의미는 아니다.

확정 시작 흐름은 `새 게임 → 시드 기반 전체 맵 생성 → 메인 캐릭터 설정 → 자율 생존 시작 → 생존 일차 누적`이다. 스탯은 능력 수치, 성격은 행동 성향, 특성은 인물의 개별 특징으로 구분한다. 구체적인 항목·포인트·효과는 아래 캐릭터 생성 절의 초기 밸런스 v0.1을 따른다.

플레이어가 생성한 메인 캐릭터가 사망하면 해당 회차의 게임 플레이를 삭제·초기화한다. 캐릭터의 진행과 소지품뿐 아니라 그 회차에 누적된 세계 변화와 플레이 진행도 초기화 대상이다. 같은 회차를 다른 생존자로 이어가는 방식은 허용하지 않는다. 

신의 개입과 인간 빙의는 자율 생존을 관찰하는 도중 선택적으로 사용하는 기능이다. 메인 캐릭터는 일시적으로 빙의한 대상과 구분하며, 어느 대상을 제어하든 메인 캐릭터의 사망은 회차 종료 조건이다. 주인공 외 인간에 대한 빙의 허용 범위, 신의 개입으로 사망을 막을 수 있는지와 제한은 미정이다.

주인공 변이는 사망과 같은 회차 종료로 처리한다. 사망 시 저장 삭제의 구체적인 범위와 방식, 새 회차의 시드 선택 방식, 캐릭터 설정 프리셋·환경설정·통계의 유지 여부는 미정이다. 회차 밖 보존 요소를 확정하지 않는다.

플레이어 권한:

- 인간과 좀비 생성.
- 건물 건설과 배치.
- 인간과 좀비에게 직접 명령.
- 인간의 욕구, 성격, 관련 판단 기준과 능력 수정.
- 좀비의 수치, 특히 소음 민감도와 이동 속도 수정.
- 개체의 상태, 행동과 판단 이유 확인.

명령의 예시로 이동, 대기, 귀가, 물품 획득과 공격을 논의했다. 일시정지와 배속은 인터페이스 구성안에 포함된다.

명령의 우선순위, 중단과 종료 조건은 최종 규칙이 필요하다. 인간은 즉각적인 위험에 처하면 명령을 중단할 수 있게 하고, 별도의 강제 명령 모드를 두는 안을 제안했지만 확정하지 않았다.

### 캐릭터 생성 — 스탯·성격·특성

캐릭터 생성 항목은 세 가지 역할로 구분한다. **스탯은 얼마나 잘하는가, 성격은 무엇을 선택하는가, 특성은 어떤 고유한 장단점이 있는가**를 결정한다. 아래 항목과 효과 방향을 채택한다. 구체적인 수치는 같은 항목의 초기 밸런스 v0.1을 따른다.

#### 생성 순서와 선택 규칙

**전체 맵 생성 완료 → 스탯 배분 → 성격 설정 → 특성 선택 → 최종 생존 성향 확인 → 자율 생존 시작**

- 스탯은 공통 기본값에서 제한된 포인트를 배분한다. 기본값·범위·총량은 아래 초기 밸런스 v0.1을 따른다.
- 성격은 각 축을 낮음·보통·높음으로 선택하며 별도 포인트 비용은 두지 않는다. 한 방향이 항상 유리하지 않게 설계한다.
- 특성은 기본 포인트를 제공하고, 단점 선택으로 추가 포인트를 얻는다. 정반대 특성의 동시 선택을 금지하고 단점으로 얻을 수 있는 포인트에 상한을 둔다. 비용과 상한 수치는 아래 초기 밸런스 v0.1을 따른다.
- 첫 버전은 실제 행동 효과를 갖는 특성 8~12개를 제공하는 방향으로 한다. 아래 12개는 승인된 구성 목록이며 다른 시스템에 의존하는 항목은 관련 시스템과 함께 제공한다.

| 스탯 | 생존·행동에 주는 영향 | 적용 예시 |
| --- | --- | --- |
| 근력 | 근접 공격과 밀치기의 위력, 무거운 물건 취급 | 좀비를 밀쳐 거리를 벌린다. 개인 물품 취급 범위는 별도 물자 규칙을 따른다. |
| 민첩 | 방향 전환, 회피와 위험에서 빠져나오는 능력 | 공격을 피하고 탈출한다. |
| 지구력 | 달리기와 전투를 지속하는 능력 | 긴 도주나 교전에서 쉽게 지치지 않는다. |
| 지각 | 위협과 탐색 단서를 알아채는 능력 | 골목의 좀비나 주변 소리를 일찍 감지한다. |
| 침착성 | 공포로 인한 행동 수행 불이익을 줄이는 능력 | 위협 속에서 공격·물품 사용을 안정적으로 수행한다. |
| 학습력 | 경험을 지식으로 정리하고 숙련을 얻는 속도 | 소음과 좀비 접근의 관계를 더 빨리 배운다. |

현재 체력·허기·피로는 변하는 상태이며 기본 스탯과 구분한다. 전투 숙련은 스탯과 별도로 관리한다. 근력이 높다고 무기를 잘 다루는 것은 아니다. 지각이 높아도 벽 너머를 전부 알지 못하고, 학습력이 높아도 경험하지 않은 지식을 자동으로 얻지 않는다. 어떤 스탯도 물림을 완전히 막거나 감염 면역을 제공하지 않는다.

#### 성격 — 자율 판단의 성향

| 성격 축 | 낮음 | 높음 |
| --- | --- | --- |
| 위험 감수 | 안전한 경로와 장소를 선호 | 필요한 물자를 위해 위험을 감수 |
| 공격 성향 | 우회·은신·도주를 선호 | 상대할 만한 좀비를 먼저 제거하려 함 |
| 이타성 | 자신의 생존과 물자 확보를 우선 | 다른 인간을 돕는 선택에 높은 가치 부여 |
| 규칙 준수 | 타인의 물품을 가져가는 데 거리낌이 적음 | 타인의 소유물을 가져가는 행동을 꺼림 |
| 비축 성향 | 당장 필요한 만큼 확보 | 미래 부족에 대비한 추가 확보를 선호 |

보통은 양극 사이의 성향이다. 위험 감수와 공격 성향은 독립적이다. 신중하지만 공격적인 인간은 소수 좀비만 골라 제거하고, 위험을 감수하지만 비공격적인 인간은 싸움을 피해 위험한 장소를 탐색할 수 있다.

성격은 자율 AI의 행동 선택에 반영한다. 직접 조작 중에는 플레이어의 선택을 강제로 빼앗지 않고 선호·심리 반응이나 판단 안내에 활용한다. 성격에 따른 심리 불이익의 구체적인 효과는 미정이다. 이타성은 도움·공유 행동, 규칙 준수는 소유권 판단이 연결될 때 행동에 영향을 준다. 생성 화면에서는 모든 성격 축을 설정할 수 있다. 사회 행동과 소유권의 세부 규칙은 미정이다.

#### 특성 — 상황별 장점과 단점

| 분야 | 장점과 효과 | 단점과 효과 |
| --- | --- | --- |
| 이동 소음 | 조용한 발걸음: 걷기 소음 감소 | 요란한 발걸음: 이동 소음 증가 |
| 물품 취급 | 정리 습관: 물품 획득·정리 시간 감소 | 서투른 손놀림: 물품 취급 시간 증가 |
| 식량 소비 | 소식가: 허기 증가 속도 감소 | 대식가: 허기 증가 속도 증가 |
| 수면 | 적은 수면: 피로 회복에 필요한 수면 시간 감소 | 많은 수면: 회복에 필요한 수면 시간 증가 |
| 일반 부상 | 빠른 회복: 일반 부상 회복 속도 증가 | 느린 회복: 일반 부상 회복 속도 감소 |
| 환경·공포 | 어둠에 익숙함: 어두운 장소에서 공포 증가 감소 | 폐쇄 공간 공포: 좁은 실내에서 공포 증가 |

같은 행의 앞 다섯 쌍은 상반된 효과여서 동시에 선택할 수 없다. 어둠과 좁은 공간은 서로 다른 상황이므로 마지막 두 특성을 정반대 쌍으로 취급하지 않는다. 추가 충돌 조합은 별도로 정의한다.

일반 부상 회복 특성은 좀비 감염을 치료하지 않는다. 감염 면역·물림 무효 특성은 초기 구성에서 제외한다. 생성 화면에서 특성을 설정할 수 있으며 단점 보상은 생성 규칙대로 계산한다.

#### 조합 예시

| 생존 스타일 | 설정 예시 | 강점과 부담 |
| --- | --- | --- |
| 조용한 탐색자 | 지각·민첩 중시, 낮은 공격 성향, 조용한 발걸음 | 위협 발견과 우회에 유리하지만 정면 전투 투자가 적다. |
| 근접 생존자 | 근력·지구력 중시, 높은 공격 성향, 대식가 | 교전을 지속하기 좋지만 식량 소비 부담이 크다. |
| 신중한 장기 생존자 | 학습력·침착성 중시, 낮은 위험 감수, 소식가 | 경험을 활용하고 식량을 아끼지만 위험 지역 탐색을 꺼린다. |

이는 조합 설명이며 고정 직업이나 별도 보너스가 아니다.

#### 초기 밸런스 v0.1 — 스탯 배분

**아래 수치는 초기 기획 기준이다.** 생성 시 범위와 수치는 메인 캐릭터 기준이며 성장 상한·NPC 분포를 자동으로 확정하지 않는다.

| 항목 | 초기값·규칙 |
| --- | --- |
| 기본 스탯 | 6개 모두 5 |
| 생성 시 범위 | 각 3~8, 정수 단위 |
| 추가 배분 | 8포인트 |
| 기본값 아래로 낮추기 | 5에서 1 낮출 때 1포인트 반환, 전체 반환량 최대 2 |
| 특성 포인트와 교환 | 불가능 |

| 상승 단계 | 단계 비용 | 기본 5에서 누적 비용 |
| --- | ---: | ---: |
| 5 → 6 | 1 | 1 |
| 6 → 7 | 2 | 3 |
| 7 → 8 | 3 | 6 |

선택을 되돌리면 해당 단계 비용을 정확히 되돌린다. 낮추기 반환은 최종 설정이 기본값 5보다 낮은 정도로 계산하고 최대 2로 제한하여 조작 반복으로 포인트를 얻지 못하게 한다. 배분 잔액이 음수면 시작할 수 없다. 8포인트로 두 스탯 7과 두 스탯 6을 만들거나, 한 스탯 8과 두 스탯 6을 만들 수 있다.

#### 초기 밸런스 v0.1 — 스탯 효과

스탯 5를 기준으로 한다. 아래 변화는 `현재 스탯 − 5`에 비례하고, 5 아래에서는 반대로 적용한다. 성장 등으로 생성 범위를 벗어나는 경우의 공식은 미정이다.

| 스탯 | 1당 변화 | 스탯 8의 효과 |
| --- | --- | --- |
| 근력 | 근접 피해·밀치기 위력 +5% | 기준의 115% |
| 민첩 | 방향 전환·공격 후 회복 시간 −3%, 회피 성공률 +1%p | 시간 91%, 회피 +3%p |
| 지구력 | 최대 행동 스태미나 +6% | 기준의 118% |
| 지각 | 감지 조건을 충족한 위협·단서의 감지 거리 +4% | 기준의 112% |
| 침착성 | 공포로 생기는 수행 불이익의 크기 −8% | 불이익의 76% |
| 학습력 | 관찰 학습·숙련 경험 획득량 +8% | 기준의 124% |

민첩은 기본 이동 속도를 올리지 않는다. 지각은 시야·장애물 제한을 무시하지 않는다. 침착성은 피해·감염 확률을 줄이지 않는다. 예를 들어 공포의 명중 불이익이 20%p이면 침착성 8에서 15.2%p가 된다. 학습력은 실제 관찰·연습에만 적용한다.

회피 성공률 상한은 전투·감염 초기 규칙을 따른다. 포위·피로·부상 등 상황 보정도 별도로 적용해야 한다. 지구력은 단기 활동용 스태미나에, 수면 특성은 장시간 누적되는 피로 회복에 작용한다. 기본 피해와 공포 불이익은 각 시스템의 초기 규칙을 따르며, 기본 감지 거리는 미정이다.

#### 초기 밸런스 v0.1 — 특성 포인트와 수치

| 선택 규칙 | 초기 기준 |
| --- | --- |
| 기본 특성 포인트 | 4 |
| 단점 보상 합계 | 최대 4 |
| 선택 수 | 장점 최대 3개, 단점 최대 2개 |
| 중복·충돌 | 동일 특성 중복 및 상반된 특성 동시 선택 금지 |
| 시작 조건 | 포인트 잔액 0 이상. 남겨도 시작 가능 |

잔액은 `4 + min(선택한 단점 보상 합계, 4) − 장점 비용 합계`로 계산한다. 스탯 포인트와 별개다. 특성 선택을 되돌리면 잔액도 다시 계산한다. 장점·단점 선택을 강제하지 않는다.

| 특성 | 비용 또는 보상 | 초기 효과 |
| --- | --- | --- |
| 조용한 발걸음 | 비용 4 | 걷기 소음 강도 ×0.75. 달리기·공격·비명 미적용 |
| 요란한 발걸음 | 보상 3 | 걷기·달리기 소음 강도 ×1.20 |
| 정리 습관 | 비용 2 | 물품 획득·보관 이전 시간 ×0.80 |
| 서투른 손놀림 | 보상 2 | 물품 획득·보관 이전 시간 ×1.25 |
| 소식가 | 비용 3 | 허기 증가 속도 ×0.85 |
| 대식가 | 보상 2 | 허기 증가 속도 ×1.20 |
| 적은 수면 | 비용 4 | 수면 중 피로 회복 속도 ×1.25 |
| 많은 수면 | 보상 3 | 수면 중 피로 회복 속도 ×0.80 |
| 빠른 회복 | 비용 3 | 조건을 충족한 일반 부상 회복 속도 ×1.25 |
| 느린 회복 | 보상 2 | 일반 부상 회복 속도 ×0.80 |
| 어둠에 익숙함 | 비용 2 | 어둠 원인의 공포 증가량 ×0.60 |
| 폐쇄 공간 공포 | 보상 2 | 좁은 실내 체류 시 게임 시간 10분당 공포 +5, 이 원인만으로는 공포 40까지 상승 |

공포는 이 초기안에서 0~100 척도를 사용한다. 폐쇄 공간 공포는 게임 시간에 비례해 적용하고, 이미 공포가 40 이상이면 이 원인으로 추가 상승하지 않는다. 다른 위협은 공포를 40 이상 올릴 수 있다. 공간을 벗어나면 추가 상승만 멈추고 일반 공포 회복 규칙을 따른다. 이 특성으로 입력을 강제로 취소하지 않는다. 좁은 공간 판정은 미정이며 일반 공포 증감의 초기 기준은 인간 생존 상태 항목을 따른다.

효과는 지정한 수치에만 곱한다. 소음 강도 감소가 감지 거리의 동일 비율 감소를 보장하지 않는다. 정리 습관은 탐색 전체·공격·치료 속도를 올리지 않는다. 적은 수면으로 회복 속도가 25% 증가하면 같은 피로를 회복하는 시간은 20% 줄어든다(기준 8시간이면 6.4시간). 빠른 회복은 감염 치료나 출혈의 즉시 해결이 아니다. 향후 같은 수치에 다른 보정이 추가될 때의 합산·중첩 규칙은 별도 확정한다.

#### 초기 밸런스 v0.1 — 조합 예시

| 조합 | 특성 포인트 계산 | 교환 관계 |
| --- | --- | --- |
| 기본 은신형 | 기본 4 − 조용한 발걸음 4 = 0 | 단점 없이 걷기 소음 관리에 집중 |
| 물자 절약형 | 기본 4 + 느린 회복 2 − 소식가 3 − 정리 습관 2 = 1 | 식량·취급 효율 대신 부상 회복 부담 |
| 활동 시간 중시형 | 기본 4 + 대식가 2 − 적은 수면 4 − 정리 습관 2 = 0 | 수면·취급 효율 대신 식량 부담 |

#### 미정 사항

- 성장·숙련 획득의 세부 방식과 성장 상한. 생성 수치는 초기 밸런스 v0.1을 따른다.
- 기본 피해·부상 회복량·회피 상한은 전투·감염 초기 규칙을 따르며 탐색 세부 규칙은 미정이다. 수면·공포와 상태 중첩은 인간 생존 상태 항목, 특성 비용·효과는 생성 초기 밸런스 v0.1을 따른다.
- 성격의 판단 가중치, 직접 조작 중 심리 반응의 표시·효과.
- 도움·공유·소유권, 일반 부상 회복, 어둠·좁은 공간 판정의 세부 규칙.
- 최종 생성 화면과 설정 결과의 생존 성향 요약 방식.

### 선택 기능 — 인간 빙의와 직접 플레이

플레이어는 신의 관찰·개입 모드에서 특정 인간에 빙의해 그 인물의 선택과 행동을 직접 결정할 수 있다.

인간 빙의와 직접적인 행동 선택은 선택 기능이다. 기본 진행은 자율 AI 생존이며 빙의는 필수 절차가 아니다. 이동, 탐색, 물품 획득·사용, 식사, 휴식, 은신, 도주와 공격을 선택 가능한 행동의 기본안으로 제안한다. 빙의가 무적이나 감염 면제를 뜻하지는 않으며 일반 생존 규칙을 적용하는 것을 기본안으로 둔다.

제안하는 제어 흐름은 `인간 선택 → 빙의 → 직접 행동 선택 → 빙의 해제 → 자율 AI 복귀`다. 나머지 세계는 계속 시뮬레이션하는 방향이다. 정확한 키보드 이동·클릭 명령 방식, 카메라, 행동 대기열, 빙의 전환 조건, 위험 시 AI 개입과 빙의 해제 시 처리와 신의 정보·캐릭터 지식의 표시 범위는 미정이다. 주인공 사망·변이 시 회차 종료는 전투·감염 초기 규칙이다. 좀비 빙의는 이번 확정 범위에 포함하지 않는다.

## 11. 미정 사항

- 캐릭터 생성 수치·포인트·기능 의존성의 세부 규칙은 10절을 따른다. 빙의·신의 권한과 주인공 사망 규칙의 관계는 미정이다.
- 주인공 변이 시 회차 종료는 확정이며, 남은 사항은 저장 삭제 방식과 회차 밖 데이터 보존 범위, 재시작 시 시드 선택 방식.

- 시드 입력·선택 방식, 같은 시드의 재현 범위, 맵 생성 요소와 배치 규칙.
- 생존 일차의 첫날 기준과 날짜 전환 시각.
- 지도 크기, 건물 수, 내부 공간과 상호작용 거리.
- 그래픽 크기, 애니메이션 수준과 UI 배치. Unity 버전·렌더링 구성·대상 플랫폼은 미정이다.
- 생존 상태의 남은 설계는 4절을 따른다. 아이템 초기 재고·취급 시간·소지 한도는 [Items.md](Items.md)의 초기 기준을 따르며 탐색 세부 규칙은 미정이다.
- 개인 소지·거처 보관의 범위, 물자 소유권·공유·거래 규칙. 생산·배송망은 제외한다.
- 빙의 조작·카메라·행동 대기열·AI 우선순위·해제 및 사망·변이 처리.
- 시작 시 좀비 수, 피해 규모와 인간별 초기 지식.
- 확정 성격·스탯의 수치 범위와 가중치, 전투 계산식, 무기 규칙과 사망 처리.
- 감염·증상·치료제의 승인 초기 규칙은 전투·감염 초기 규칙 절을 따른다. 해당 절에 명시한 남은 세부 결정은 유지한다.
- 소리 전파, 청각, 추적과 좀비 인지의 세부 규칙.
- 학습 기준, 기억의 약화와 지식 전달.
- 명령 우선순위와 강제 명령 동작.
- 저장·불러오기, 상태 보존과 초기 인구를 넘어서는 성능 목표.
