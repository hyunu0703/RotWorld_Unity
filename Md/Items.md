# RotWorld — 아이템 기획서

## 공통 수량·이전 규칙

- 1개당 소지 한도 1칸을 사용하며 인간 한 명의 기본 합계 한도는 8개이며 가방 아이템 확보 시 총 24개로 확장된다. 기존 음식·물은 1회분을 1개로 계산한다. 무게 계산은 없다.
- 장소 재고 → 획득 → 소지품 → 사용·소비 또는 장소 공개 재고로 보관한다. 생산·배송·자동 재입고는 없다.
- 획득·보관은 건물 입구 중심 0.55타일 이내에서 수행한다. 기본 10초에 기존 상태·취급 특성 보정을 적용한다. 완료 시 양쪽 수량·위치·한도를 재확인한다.
- 완료 전 중단에는 물품을 이전·소비하지 않는다. 여러 인간이 마지막 물품을 취급하면 먼저 완료한 인간만 얻는다.
- 전체 장소 재고 + 모든 인간의 소지품(시신·변이 전 인물 보관분 포함) + 버린 물품의 별도 집계량 + 누적 소비량 = 초기 총량을 유지한다. 버린 물품의 집계와 실제 지면 보존·재획득 가능 여부는 구분한다.
- 가방은 소지 한도를 확장하는 아이템이다. 개인 창고·소유권·공유·거래·시신 약탈의 세부 규칙과 제공 범위는 미정이다.

간식·식사·물의 시작 재고·한도·시간은 조정 가능한 초기 기본안이며 최종 밸런스는 미정이다. 붕대·쇠파이프는 승인된 초기 규칙이다. 음식·물 섭취의 초과 효과를 저장하지 않으며, 붕대·쇠파이프는 먹을 수 없다.

## 아이템 출현 규칙

- 간식·식사·물·붕대·쇠파이프는 모든 건물에서 구할 수 있다. 특정 이름의 건물에만 나오는 전용 아이템으로 제한하지 않는다.
- 무기는 무기별로 지정된 특정 이름 건물에서 출현할 확률이 매우 높다. 다른 건물에서도 매우 낮은 확률로 출현한다. 특정 이름 건물이 생성되지 않아도 다른 건물에서 무기를 구할 가능성은 남는다.
- 출현 가능은 모든 건물에 해당 아이템이 반드시 있다는 뜻이 아니다. 정확한 확률·배치 수량·무기별 고확률 건물 이름은 미정이다.
- 가방의 출현 범위·확률·수량은 미정이다.
- 자동 보충 없이 맵 생성 시 정해진 재고를 탐색·획득한다.

## 초기 재고

인간의 시작 소지량은 아이템 목록을 따른다. 장소별 재고는 모든 건물에서 기존 아이템이 출현할 수 있는 규칙과 무기의 건물별 확률 차이를 따른다. 장소별 확정 수량은 미정이다.

## 자율 치료와 회복 아이템 확보

회복 아이템이 없으면 수색을 통해 확보한다. 붕대는 보유 2개부터 붕대만을 목적으로 추가 수색하지 않는다. 전체 회복 아이템 합계가 5개 이상이면 회복 아이템만을 목적으로 추가 수색하지 않는다. 붕대도 전체 합계에 포함한다. 목표 수량은 전용 수색을 멈추는 기준이며 소지 자체의 상한은 아니다. 0개 초과·목표 미만일 때의 추가 수색 기준과 붕대 외 회복 아이템별 목표는 미정이다.

다른 수색 도중 회복 아이템을 발견하면 확보 후보로 판단한다. 다만 더 우선하는 아이템을 수색 중이면 회복 아이템을 가져가지 않는다. 소지 한도와 현재 필요도를 함께 고려한다. 붕대는 출혈 중인 상처에 사용하며 실제 지혈 방법은 아이템 규칙을 따른다. 위험 대응·실제 지혈·다른 긴급 욕구 간 세부 우선순위는 미정이다.

## 소지 한도와 수색 우선순위

기본 소지 한도는 8개다. 가방 아이템을 구하면 총 소지 한도가 24개로 확장된다. 음식·물 1회분은 1개로 계산한다. 한도가 찼다면 현재 필요한 아이템의 우선순위를 비교해 해당 수색을 하지 않거나 가장 필요 없는 소지품을 버려 수량을 줄인 뒤 필요한 아이템을 확보한다. 일률적인 고정 순위가 아닌 현재 상태에 따른 판단이며 세부 점수·동률 기준은 미정이다. 버린 물품의 지면 보존·재획득 규칙은 미정이다.

## 붕대

출혈 중인 상처 하나를 지정한다. 이미 지혈된 상처에는 사용할 수 없다. 완료 전 중단하면 붕대는 남고 출혈은 계속된다. 물린 상처도 지혈하지만 감염을 치료하거나 감염 시작·변이 시각을 바꾸지 않는다. 정리 습관·서투른 손놀림은 기존 획득·보관 시간만 바꾸며 붕대 사용 시간을 바꾸지 않는다. 일반 상처와 물린 상처는 지혈 후 승인된 회복 조건을 누적 6시간 충족하면 회복한다. 빠른 회복·느린 회복은 상처 회복에 적용되며 지혈 시간에는 적용되지 않는다.

## 쇠파이프

- 인간은 무기 없이 시작한다. 모든 건물에서 출현 가능하며 지정된 특정 이름 건물에서는 매우 높은 확률, 다른 건물에서는 매우 낮은 확률로 출현한다. 고확률 건물 이름·정확한 확률·초기 수량은 미정이다.
- 장착·해제 버튼으로 선택하고 게임 시간을 사용하지 않는다. 장착해도 소지품 수량과 사용 칸 수는 변하지 않는다.
- 공격 중 장착을 바꾸려면 먼저 공격을 중단한다. 장착 변경으로 준비·재사용 시간을 줄일 수 없다.
- 장착한 쇠파이프를 보관하면 장착도 해제한다. 내구도·공격 시 물품 소비는 없다.
- 자율 인간은 가진 쇠파이프를 장착한다. 공격 성향 보통·높음은 위협이 없고 소지 공간이 있을 때 직접 확인한 재고에서 하나까지만 확보한다. 긴급 욕구 해결을 우선한다.
- 피해·사거리·공격 주기·근력/민첩 보정·소음은 [GameDesign.md](GameDesign.md)의 전투·감염 초기 규칙을 따른다.

## 미정 사항

추가 무기·도구·약품, 무게·무기 내구도·제작·수리·갑옷·시신 약탈의 도입 여부와 세부 규칙은 미정이다. 추가 물품의 규격·배치는 미정이다. 감염 치료제는 첫 버전에 제공하지 않는다.
