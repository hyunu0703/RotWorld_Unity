# RotWorld — 맵 생성 기획서

## 전체 생성 방향

하나의 불규칙한 섬 안에 복합 시가지·분산된 마을·고밀도 도심·강변 도시·산업 외곽을 모두 포함한다. 바다가 섬을 둘러싸고 실제 하천이 섬 내부를 지나 바다로 이어진다. 전체 맵을 하나의 템플릿으로 채우거나 템플릿을 선택하는 UI는 사용하지 않는다.

전체 지역 구성 + 맵 설정 + 시드로 생성한다. 같은 생성기 버전과 설정·시드에서는 같은 지형·지역·도로·건물을 재현한다. 인구·좀비·물자 배치는 별도 난수 흐름으로 처리하며 도시 구조를 바꾸지 않는다. 초기 인간 수는 고정하지 않는다.

아래 수치는 승인된 시제품 출발 기준이며 최종 밸런스는 실제 이동·탐색·생존과 성능을 확인해 조정한다.

## 지역 면적 비율

바다·얕은 바다·강을 제외한 육지 면적을 기준으로 한다. 해변은 자연 지역에 포함한다.

| 지역 | 기본 비율 | 공간 구성 |
| --- | ---: | --- |
| 복합 시가지 | 23% | 도심 주변에 주거·상업·공공시설 혼합 |
| 분산된 마을 | 15% | 본도시와 분리된 생활권 여러 곳 |
| 고밀도 도심 | 8% | 연결성이 좋은 중심부의 조밀한 개발 |
| 강변 도시 | 10% | 실제 하천을 따라 길게 형성된 시가지 |
| 산업 외곽 | 9% | 도시 가장자리의 큰 공장·창고 부지 |
| 자연·미개발 공간 | 35% | 숲·공터·해안 완충지와 생활권 사이 공간 |

각 비율은 시드에 따라 기본값의 약 ±3%p 안에서 변동하고 합계는 100%로 유지한다. 타일 정수화에 따른 작은 오차를 허용한다. 지역은 규칙적인 사각형이나 같은 크기의 조각으로 나누지 않고 중심과의 거리·하천·해안·녹지에 따라 경계를 형성한다.

도심 → 복합 시가지 → 미개발 공간 → 독립된 마을의 흐름을 만든다. 산업 지역은 외곽에 모으고 간선도로와 연결한다. 강변 지역은 목표 면적과 함께 하천과의 실제 관계를 우선한다.

## 맵 크기와 생활권 및 다리 수

| 맵 크기 | 주요 도심 | 분산된 마을 | 다리 |
| --- | --- | ---: | ---: |
| 소형 128×128타일 | 1곳 | 2곳 | 2개 |
| 중형 256×256타일 | 1곳 | 3곳 | 2~3개 |
| 대형 512×512타일 | 주요 도심 1곳 + 보조 중심 1곳 | 4~5곳 | 3~4개 |

마을 사이에는 가능하면 마을 한 곳 너비 정도의 미개발 공간을 둔다. 도심의 주택이 연속해서 이어지는 형태로 모든 마을을 연결하지 않는다. 소형은 건물 규격을 임의 축소하지 않고 시설 수·도로 가지 수를 줄인다. 대형은 목표 기기의 성능 검증이 필요하다.

타일은 이동·전투에 쓰는 공간 단위다. 그래픽의 원본 픽셀 수와는 구분하며 표시 규칙은 [GraphicDesign.md](GraphicDesign.md)를 따른다.

## 지역별 도로·건물·밀도 기준

도로 간격은 도로 가장자리 사이의 블록 내부 폭이며, 건물 크기는 바닥 점유 영역이다. 아래 크기는 외형과 부지 기준이며 실내·층별 시스템을 확정하지 않는다.

| 지역 | 도로 간격 | 대표 건물 크기 | 필지 채움 비율 | 녹지·빈 공간 |
| --- | --- | --- | ---: | --- |
| 고밀도 도심 | 12~20타일 | 5×6~10×12타일 | 85~95% | 작은 광장·후면 통로 |
| 복합 시가지 | 20~32타일 | 주택 4×5~7×8, 상점 6×6~10×10타일 | 60~75% | 마당·주차장·소공원 |
| 분산된 마을 | 16~28타일 | 주택 4×5~6×7, 생활시설 약 6×8타일 | 35~50% | 넓은 마당·빈 땅·숲 |
| 강변 도시 | 18~30타일 | 4×6~8×10타일 | 45~65% | 연결된 수변 공간 |
| 산업 외곽 | 28~44타일 | 창고·공장 10×12~18×24타일 | 40~55% | 작업장·적재 공간·완충 녹지 |

필지 채움 비율은 사용 가능한 필지 중 실제로 건물을 놓는 비율이며 지역 면적 중 건물 바닥의 비율과 다르다. 개발 밀도 설정은 지역별 기준을 상대적으로 보정하며 다섯 지역의 최소 시설을 제거하지 않는다. 지형·도로 접근성 때문에 목표 시설 수를 채우지 못하면 겹치거나 물을 덮지 않고 빈 공간을 남긴다.

건물 사이 간격은 도심 1~2타일, 복합 시가지 2~4타일, 마을 4~8타일을 출발 기준으로 한다. 큰 산업 부지가 들어가지 않으면 최소 규격의 창고나 열린 작업 공간을 사용한다. 최소 규격보다 작게 줄여 다섯 지역을 형식적으로 채우지 않는다.

## 다양한 도로 배치

전체 지도에 가로·세로 축을 먼저 깔지 않는다. 지역 중심과 다리 위치를 먼저 정하고 간선도로로 연결한 뒤 각 생활권의 내부 도로를 만든다.

| 지역 | 도로 형태 |
| --- | --- |
| 고밀도 도심 | 방향이 조금 다른 짧은 격자·엇갈린 교차로·사선 연결 |
| 복합 시가지 | 방향이 다른 작은 블록 묶음·완만한 연결도로·순환길 |
| 분산된 마을 | 중심길에서 갈라지는 가지형 도로·짧은 순환길 |
| 강변 도시 | 강의 굴곡을 따라가는 도로·다리 접근로 |
| 산업 외곽 | 큰 부지를 감싸는 순환도로·짧은 진입도로 |

- 직선은 한두 블록 길이에서 방향이 바뀌거나 다른 길과 합류하도록 구성한다.
- 사거리 반복보다 T자 합류와 엇갈린 연결을 활용한다.
- 해안과 강 주변에서는 지형을 따라 우회한다.
- 주요 지역 사이에는 대체 경로를 확보하며 막다른 길은 생활도로 일부에 둔다.
- 곡선과 사선도 픽셀 격자 위의 계단 형태로 표시한다.
- 간선도로 폭은 차도와 인도를 포함해 6타일, 생활도로는 4타일을 기본으로 한다.
- 도로의 점선은 표시하지 않는다.
- 도로 중심뿐 아니라 전체 폭과 주변 건물 공간이 물을 침범하지 않는지 검사한다.

도로 형태는 무작위 흔들림만으로 결정하지 않는다. 연결할 목적지·하천·해안·보존할 부지가 방향 전환의 근거가 된다.

## 하천과 다리

강 1개를 기본으로 하며 크기별 지정 범위의 다리를 서로 떨어뜨려 배치한다.

중형은 도심·시가지 연결용 주요 다리 1개, 떨어진 우회용 다리 1개를 두고 산업 연결이 필요하면 1개를 추가한다. 강 양쪽에는 3~6타일의 열린 수변 공간을 우선 확보하며 다리 접근로에서만 도로가 강에 연결되도록 한다.

강 위에는 승인된 교량 영역만 통행 공간으로 생성한다. 일반 도로·인도·건물·출입구·보행 진입로는 강과 바다에 배치하지 않는다. 교량 양끝은 실제 육지 도로망과 연결되어야 한다.

## 생성과 검증 순서

1. 독립 지형 시드로 불규칙한 섬·모래사장·얕은 바다 생성
2. 하천·생활권 중심·마을 수와 지역 면적 계획
3. 횡단 가능한 위치에서 다리 수와 접근부 확보
4. 최소 규격을 지키는 지역별 핵심 부지 보존
5. 지역 중심·다리를 간선도로 및 우회 경로로 연결
6. 지역별 내부 도로와 필지·건물·진입 통로 생성
7. 물자와 인간·좀비의 중복 없는 위치 배치
8. 수역 침범·지역 존재·도로 및 출입구 연결·재현성 검사

모든 건물 출입구는 통행 가능한 길과 연결한다. 물자는 모든 건물에서 출현 가능하되 세부 규칙은 [Items.md](Items.md)를 따른다. 생산·배송·자동 보충은 없다.

유효한 시작 위치가 부족하면 개체를 겹쳐 배치하지 않고 설정 변경을 안내한다. 생성에 실패하면 기존 맵을 유지한다.

## 설정 UI 범위

플레이어에게는 기존의 맵 크기·시드·개발 밀도·인간 수·좀비 수·물자량만 제공한다.

지역 비율·지역별 밀도·마을 수·도로 간격·건물 크기·다리 수·도로 형태 확률은 내부 생성 규칙으로 사용하며 설정 UI에 값이나 조정 항목을 추가하지 않는다. 템플릿 선택 UI도 제공하지 않는다.
