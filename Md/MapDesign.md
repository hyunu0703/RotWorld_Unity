# RotWorld — 맵 생성 기획서

## 설계 방향

맵 생성은 **템플릿 + 설정값 + 시드**를 조합한다. 인구수와 독립적으로 도시 구조를 결정하며 초기 인간 수는 고정하지 않는다.

아래 템플릿과 수치는 구현 후 조정할 추천 출발안이다. 최종 밸런스와 완성 맵의 규모를 확정하는 것은 아니다.

## 추천 템플릿

| 템플릿 | 도시 구조 | RotWorld에서 기대하는 생존 상황 |
| --- | --- | --- |
| **복합 도시 — 기본 추천** | 중심 상업지, 주변 주거지, 가장자리 산업지와 녹지 | 서로 다른 장소를 탐색하고 물자 고갈에 따라 활동 범위 확장 |
| 분산된 마을 | 여러 작은 시가지가 간선도로로 연결 | 가까운 마을에 머물지, 먼 지역으로 이동할지 판단 |
| 고밀도 도심 | 조밀한 건물, 여러 교차로, 좁은 뒷골목 | 소음·추적·우회 경로가 빈번하게 연결 |
| 강변 도시 | 강 양쪽 시가지와 제한된 다리 | 특정 통로의 위험이 이동 계획에 큰 영향 |
| 산업 외곽 | 넓은 공장·창고 부지와 떨어진 주거지 | 긴 이동 거리와 적은 연결 통로를 고려한 탐색 |

**첫 구현은 ‘복합 도시’로 시작하는 것을 추천한다.** 주거·상업·산업·녹지를 모두 포함해 기존 생존 시스템을 다양한 공간에서 확인할 수 있다.

## 복합 도시의 구체적인 설정값

타일은 이동·전투에 쓰는 공간 단위다. 그래픽의 8×8픽셀 규격과는 구분하며, 그래픽 규격 자체를 이 문서에서 확정하지 않는다.

| 설정 | 추천 출발값 | 역할 |
| --- | --- | --- |
| 맵 크기 | 소형 128×128 / **중형 256×256** / 대형 512×512타일 | 인구와 별개로 선택. 대형은 성능 검증 후 제공 |
| 도시 중심 | 중형 기준 주요 중심 1곳, 보조 중심 2곳 | 모든 시설이 한곳에 몰리지 않도록 구성 |
| 개발 지역 | 전체 면적의 약 65% | 도로·건물·마당·주차장 등을 포함 |
| 자연·미개발 지역 | 약 35% | 외곽 숲·공터·완충 공간 |
| 개발 지역의 용도 | 주거 50% / 상업 25% / 산업·업무 15% / 공공·공원 10% | 공통 도로 부지를 제외한 면적 비율 |
| 간선도로 | 지도의 서로 다른 경계를 잇는 2개 축 | 도시 전체 연결 |
| 간선도로 폭 | 차도 4 + 양쪽 인도 각 1타일 | 총 6타일 |
| 생활도로 폭 | 차도 2 + 양쪽 인도 각 1타일 | 총 4타일 |
| 골목 폭 | 2타일 | 건물 사이 보조 경로 |
| 블록 한 변 | 24~40타일 | 구역별로 다른 간격 적용 |
| 도로 방향 | 직각 중심, 구역별 간격·연결 차이 | 정돈된 도시 안에서 변화 생성 |
| 막다른 골목 | 생활도로 가지의 약 10% | 일부 위험한 경로 제공 |

**256×256타일은 완성 맵의 확정 크기가 아니라 중형 비교 기준이다.** 현재 기획의 인간 걷기 속도인 게임 시간 초당 0.45타일에서는 지도를 직선으로 가로지르는 데 약 9.5분이 걸린다. 실제 우회와 탐색 시간을 확인해 조정한다.

## 건물 수와 필지 배치

건물 수는 고정하지 않고 부지에서 결정한다. 도로로 나뉜 블록을 필지로 분할하고 들어갈 수 있는 건물을 배치한다.

| 지역 | 필지 채움 비율 | 배치 특징 |
| --- | --- | --- |
| 중심 상업지 | 80~90% | 작은 간격, 도로를 향한 상점 출입구 |
| 주거지 | 60~75% | 주택·아파트와 마당·통로 혼합 |
| 산업·업무지 | 50~65% | 큰 건물, 넓은 부지·주차 공간 |
| 외곽 | 15~30% | 떨어진 건물과 넓은 빈 공간 |

채움 비율은 **건물을 놓을 수 있는 필지 중 실제로 사용하는 비율**이다. 나머지 필지는 공터·주차장·녹지 등으로 처리한다. 건물 종류와 크기에 따라 최종 건물 수가 달라진다.

배치에는 다음 조건을 적용한다.

- 모든 건물 출입구를 통행 가능한 길과 연결한다.
- 주요 도로망을 하나로 연결한다.
- 주요 중심 사이에는 가능하면 대체 경로를 만든다.
- 편의점·마트·약국 등의 시설을 용도에 맞게 분산한다.
- 건물이 들어가지 않으면 빈 공간으로 남긴다.
- 물자는 기존 기획대로 모든 건물에서 출현 가능하게 유지한다. 아이템별 상세 규칙은 [Items.md](Items.md)를 따른다.

## 인구·좀비·물자와 도시 생성의 분리

```text
템플릿 + 도시 설정 + 지형 시드
               ↓
도로·구역·건물 생성
               ↓
인간 수·좀비 수·물자 설정 + 배치 시드
               ↓
생존 시작
```

초기 인간 수는 고정하지 않는다. 같은 도시에서 인간 수와 좀비 수를 바꿔 비교할 수 있게 한다. **유효한 시작 위치가 부족하면 겹쳐 생성하지 않고 설정 변경을 안내한다.**

## 설정 제공 범위

플레이어에게는 우선 **템플릿·맵 크기·시드·개발 밀도·인간 수·좀비 수·물자량**을 제공한다. 도로 폭과 필지 분할 같은 세부 값은 개발용 설정으로 두고 조정하는 것을 추천한다.

지형 시드와 배치 시드를 플레이어 화면에서 각각 입력하게 할지, 하나의 입력 시드에서 내부적으로 파생할지는 미정이다.
