# RotWorld — 그래픽 제작 규칙

## 목표와 적용 범위

WorldBox처럼 작은 인물과 조밀한 세계가 보이는 저해상도 픽셀 아트를 목표로 한다. 배경과 건물·인간·좀비는 RotWorld의 현대 도시와 좀비 생존에 맞춘다.

‘WorldBox처럼 만들어줘’라는 설명만으로 동일한 결과를 보장하지 않는다. 원하는 줌 상태의 기준 이미지와 원본 규격을 정하고 실제 Unity 화면에서 크기·밀도·색감을 비교한다. WorldBox의 공개 자료에서 확인하지 못한 원본 규격은 추정으로 표시한다.

이 문서의 수치 예시는 제작 방식을 설명하기 위한 것이며 최종 그래픽 규격을 확정하지 않는다. 맵 생성 규칙은 [MapDesign.md](MapDesign.md), 게임 규칙은 [GameDesign.md](GameDesign.md)를 따른다.

## 크기 기준의 구분

| 기준 | 의미 | 예시 — WorldBox 실측값 아님 |
| --- | --- | --- |
| 원본 해상도 | 그림을 구성하는 실제 픽셀 수 | 인간 프레임 8×12픽셀 |
| 상대적 크기 | 인간·건물·도로 사이의 비율 | 주택 폭이 인간 폭의 몇 배인지 |
| 화면 확대 배율 | 원본 1픽셀이 화면에서 차지하는 크기 | 3배 확대 시 3×3화면 픽셀 |

인물 그림만 작게 만들지 않고 건물·도로와의 비율 및 한 화면에 보이는 범위를 함께 맞춘다. 프레임 크기와 투명 여백을 제외한 실제 그림 영역도 구분한다.

제작 전에 다음 기준을 정한다.

- 원하는 기본 줌 상태의 참고 이미지
- 에셋 종류별 원본 크기와 실제 그림 영역
- 공통 팔레트와 명암 표현 방식
- 월드 에셋의 공통 픽셀 밀도와 PPU
- 기준 화면 해상도와 기본 줌
- 원본 해상도보다 작은 표시가 필요한 축소 줌의 별도 처리 방식

## 정사각형 픽셀과 색 덩어리의 구분

파일의 실제 픽셀과 그림 속에서 픽셀처럼 보이는 색 덩어리는 다르다. 같은 색의 픽셀 여러 개가 붙으면 직사각형이나 불규칙한 모양의 덩어리가 될 수 있으며, 이는 정상적인 픽셀 아트 표현이다.

지켜야 할 기준은 **모든 색 경계가 하나의 일정한 원본 픽셀 격자에 맞고, 원본 픽셀 하나가 화면에서 같은 크기의 정사각형으로 표시되는 것**이다. 모든 색 덩어리를 정사각형으로 만들 필요는 없다.

## AI 생성 이미지의 한계와 사용 기준

이미지 생성 AI는 픽셀 아트를 일정한 저해상도 격자 위의 그림 대신 픽셀처럼 보이는 고해상도 그림으로 만들 수 있다. 이 경우 그림 속 픽셀처럼 보이는 덩어리의 폭과 높이 또는 경계 간격이 일정하지 않을 수 있다.

프롬프트에 ‘정사각형 픽셀’을 적는 것만으로는 해결을 보장하지 않는다. Point 필터를 적용해도 원본 그림에 이미 포함된 불규칙한 격자가 고쳐지지는 않는다.

| 제작 방식 | 적합한 용도 | 격자 유지 방법 |
| --- | --- | --- |
| AI 생성 이미지를 그대로 사용 | 분위기·디자인 시안 | 최종 게임용 격자 보장 어려움 |
| 생성 이미지 축소 후 픽셀 단위 정리 | 비교적 큰 건물·소품 | 목표 해상도로 변환한 뒤 실루엣·색·경계 정리 |
| 지정 크기의 캔버스에서 픽셀 단위 제작 | 작은 인간·좀비·지형 타일 | 제작 시작부터 실제 원본 격자 사용 |

작은 에셋은 처음부터 목표 해상도의 격자에서 제작하는 방식을 우선한다. 고해상도 이미지를 단순 축소하면 얼굴·팔·다리 등 필요한 형태가 사라질 수 있다. 최근접 축소도 미술적 가독성이나 기존 격자의 정확한 복원을 보장하지 않는다.

## 제작 흐름

```text
참고 이미지·AI 시안
        ↓
최종 원본 규격 결정
        ↓
실제 저해상도 격자에서 제작·정리
        ↓
팔레트·투명도·프레임 정렬 검증
        ↓
Unity에서 정수 배율로 표시
        ↓
기준 이미지와 실제 장면 비교
```

- 최종 원본은 명시한 픽셀 크기로 제작하고 확대본과 구분한다.
- 단단한 픽셀 경계에는 안티앨리어싱을 사용하지 않는다. 반투명 효과가 필요한 경우 기본 스프라이트와 구분해 설계한다.
- 같은 장면의 월드 에셋은 공통 픽셀 밀도를 사용한다.
- 제한된 공통 팔레트와 적은 명암 단계로 작은 크기에서도 형태가 구분되게 한다.
- 애니메이션 프레임은 동일한 캔버스 크기와 기준점을 사용한다. 의도하지 않은 프레임 간 위치 흔들림을 확인한다.
- 인물과 건물의 발밑 기준점을 정해 배치와 앞뒤 정렬에 사용한다.

## Unity에서 정사각형 픽셀 유지

원본 격자가 정확해도 화면 확대·축소나 비율 변경 과정에서 픽셀 형태가 깨질 수 있다.

| 항목 | 적용 기준 |
| --- | --- |
| 텍스처 필터 | Point |
| 압축 | 기본 픽셀 에셋은 None |
| Mip Maps | 기본 픽셀 에셋은 Off |
| 픽셀 밀도 | 월드 스프라이트의 PPU를 통일하고 Pixel Perfect Camera의 Assets Pixels Per Unit과 일치 |
| 카메라 | 직교 카메라와 프로젝트 구성에 맞는 Pixel Perfect Camera 설정 사용 |
| 확대 | 가로·세로 동일한 정수 배율 사용 |
| 화면 비율 | 비율을 유지하며 필요 시 여백 또는 표시 범위 조정. 가로·세로를 따로 늘리지 않음 |
| 배치 | 렌더링 위치와 카메라를 픽셀 격자에 맞춰 이동 시 흔들림 확인 |
| 회전·크기 변경 | 기본 에셋의 임의 회전과 비정수 크기 변경을 피하고 필요한 방향은 별도 프레임으로 제작 |
| 후처리 | 기본 검증에서는 안티앨리어싱·블러 등 픽셀 경계를 흐리는 효과 비활성화 |

예를 들어 8×12픽셀 원본을 24×36화면 픽셀로 표시하면 원본 픽셀 하나는 3×3 정사각형이다. 24×48로 늘리면 원본 픽셀 하나가 3×4 직사각형이 된다.

Point 필터만으로는 충분하지 않다. 비정수 배율에서는 원본 픽셀마다 차지하는 화면 픽셀 수가 달라질 수 있으므로 정수 배율과 화면 비율 유지를 함께 적용한다. 기준 화면이 출력 화면에 정수 배율로 들어가지 않으면 여백이나 표시 범위 조정 정책을 사용한다.

시뮬레이션의 이동 위치와 화면에 표시하는 픽셀 정렬 위치는 구분할 수 있다. 화면 정렬 때문에 이동 속도나 길찾기 계산을 임의로 바꾸지 않는다.

원본보다 작게 보여주는 축소 줌은 모든 원본 픽셀을 정사각형으로 보존하면서 동시에 표시할 수 없다. 축소 시의 생략·간소화 표현은 별도 규칙으로 정하고, 정수 확대 기준과 혼동하지 않는다.

## 시제품과 검증

먼저 인간 1종·좀비 1종·주택 1채·도로·인도로 작은 장면을 만든다. 원본 1배 보기, 정수 배율 확대 보기, 실제 Unity 화면을 비교한 뒤 에셋 종류를 늘린다.

- 원본 크기와 스프라이트 프레임 크기가 지정값과 일치하는지 확인
- 실제 그림 영역과 투명 여백 확인
- 픽셀 경계·팔레트·불필요한 반투명 가장자리 확인
- 인물·건물·도로의 상대적 크기와 화면 밀도 확인
- 카메라 이동·인물 이동·애니메이션 중 격자 흔들림 확인
- 목표 화면 해상도와 줌 단계별 정사각형 픽셀 유지 확인
- 타일 사이 틈과 아틀라스 인접 그림의 색 번짐 확인

원본 크기·격자·배율은 수치로 검증한다. WorldBox와 유사한 시각적 느낌은 기준 이미지와 비교해 조정한다. 실행하지 않은 Unity 검증은 미검증으로 기록한다.

## 작업 지시 예시

> 첨부한 WorldBox 화면을 기준으로 RotWorld의 작은 픽셀 그래픽을 구현해줘. 인물의 화면상 크기, 건물·도로와의 비율, 한 화면에 보이는 밀도를 맞추고 배경은 현대 도시로 바꿔줘.
>
> 픽셀처럼 보이는 고해상도 그림이 아니라 실제 저해상도 격자에 맞는 게임용 원본이 필요해. 먼저 원본 규격·공통 팔레트·PPU·기준 해상도·기본 줌을 제안해줘. WorldBox의 확인되지 않은 규격은 추정이라고 표시해줘.
>
> 작은 인간·좀비·지형 타일은 지정된 원본 크기의 격자에서 픽셀 단위로 제작해줘. AI 생성 이미지를 사용한다면 시안과 최종 게임용 원본을 구분하고, 최종 결과는 격자를 정리하고 검증해줘.
>
> 모든 원본은 같은 픽셀 밀도를 사용하고, 안티앨리어싱 없이 제작해줘. 확대 시에는 가로·세로 동일한 정수 배율을 사용해 실제 픽셀 하나가 정사각형으로 표시되게 해줘.
>
> 먼저 인간 1종·좀비 1종·주택 1채·도로와 인도로 작은 장면을 만들어줘. 원본 1배 보기와 정수 배율 확대 보기, 실제 Unity 화면을 함께 확인한 뒤 나머지 에셋으로 확장해줘.
