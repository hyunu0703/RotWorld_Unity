# 최적화 비교 검증

저장소 루트에서 실행합니다. Node.js, .NET 10 SDK, Unity 6000.3.23f1의 CoreModule이 필요합니다.

```powershell
node Tools/OptimizationVerification/verify.cjs
node Tools/OptimizationVerification/verify-movement.cjs
node Tools/OptimizationVerification/verify-dust.cjs
node Tools/OptimizationVerification/verify-simulation.cjs
```

일반·이동·연속 시뮬레이션 도구는 설치 위치가 다르면 UNITY_EDITOR_DIR 환경변수에 Editor 디렉터리를 지정할 수 있습니다. 먼지 검증 도구의 기본 설치 경로는 소스의 참조 경로에 표시되어 있습니다. 모든 생성물은 Git에서 무시하는 RotWorld/Temp 아래에 보관합니다.

## 변경 내용

1. 일반 반격과 협동 지원자 검색에 주변 행동 좌표 인덱스 적용
2. 최근접 검색의 전체 후보 정렬 제거와 동일 거리의 기존 사전 또는 인구 인덱스 순서 보존
3. 먼 거리의 추적자도 포함하는 인간별 추적 관계 기록
4. 고정 지형 지도에서 실제 A스타 탐색이 읽은 모든 점유 영역을 기록하고 해당 영역이 그대로인 경로만 재사용
5. 변환 후보와 충돌 여유 영역의 변경만 감시하고 무관한 위치 변경에는 실패 검색 재사용
6. 지도 부모별 먼지 연출과 픽셀 렌더러·배열 재사용, 재생 상태·난수 호출 순서 초기화
7. 지도 텍스처 소유 픽셀 버퍼에 직접 기록해 대형 관리 배열과 SetPixels32 복사 제거
8. 변경 없는 카메라 계산 생략, 일차 변경 시에만 일차 문자열 생성, 재사용 문자 배열로 시계 표시
9. 사망 시 추적·공격·협동 관계가 있는 유닛만 통지하고 원래 사전 순서 유지, 밀집 통지는 선형 필터 선택
10. 시야 행별 후보 범위 제한과 이동 구간 안의 동일 타일·몸체 영역 중복 검사 제거
11. 같은 시간 진행을 시작한 인간끼리 생존 시간 누적 공유, 개인별 시간 추가·쓰러짐·제거는 상태 분리
12. 지도 타일별 기본색·경계색 결정과 질감이 있는 픽셀에만 해시 계산

감지·공격 주기, 공격 거리, 충돌 판정, 이동 소단계, 협동 역할 규칙, 변환 시점과 지도 해상도는 유지합니다. 프레임 끝 공유 충돌 좌표와 이동 소단계의 실제 행동 좌표를 별도로 관리합니다. 지도 지형은 현재처럼 생성 완료 후 고정된 상태를 전제로 경로와 변환 검색을 재사용합니다. 지도 생성의 프레임 분산과 화면 밖 시뮬레이션 중단은 적용하지 않았습니다.

## 검증 범위와 결과

기준 커밋 f8e977d457b282adf3aa0f6177426f3124746e6f의 소스를 git show로 읽고 현재 소스와 비교합니다. 검증 함수는 가능한 경우 실제 현재 소스에서 추출합니다.

- 지도·경로·픽셀·감지·분리 판정, 반격 대상 선택, 협동 위협·지원자 선택, 경로 캐시와 변환 실패 캐시의 즉시 무효화: 837,567건 통과
- 지도 128/256/512, 시드 12345/7/-129 검사, 128/256 지도 전체 픽셀 색상 비교
- 128/-129 생성은 변경 전후 모두 기존 오류인 마을 주거 부지 부족으로 동일하게 실패
- 이전 화면 멈춤의 경계 사례: 동일 최종 좌표에서 반복 503,317회에서 1회로 감소 유지
- 일반 이동 10,000건과 충돌 차단 시 종료 비교 통과
- 먼지의 프레임 상태 594건, 반복 대여, 정지, 부모 파괴 시 풀 정리 비교 통과
- 시야·지형 구간 10,000쌍, 무관한 영역 변경과 실제 의존 영역 변경, 생존 수치 생성·분리·고정·고갈의 비트 단위 동일성 포함
- 연속 시뮬레이션: 초기 17·60·120개에서 진행 중 각 30개 추가 소환, 총 3,500프레임에서 상태 5,732,897건 비교 통과
- 협동 상태 관찰 6,904회, 공격 상태 관찰 7,304회, 인간 감염 변환 63건과 시나리오별 좀비 쓰러짐 포함
- 전체 게임 스크립트 Unity 참조 어셈블리 기반 컴파일: 오류 0, 경고 0

연속 검증은 이동·전투·경로·감지·생존 수치의 실제 코드를 실행하지만 Unity의 개체 수명과 시계·표시 컴포넌트는 대역을 사용합니다. 기준 코드에는 이전에 확인된 무진행 이동 반복 종료 조건만 추가해 정지 버그가 비교를 막지 않도록 합니다. Unity 자체의 플레이 모드 실행이나 실제 콜백 순서·렌더링 성능 검증은 아닙니다.

먼지 검증은 실제 Play·Update 코드와 최소 Unity 개체 대역을 사용합니다. Unity 네이티브 렌더러 동작 자체의 검증은 아닙니다. 지도 픽셀 비교는 동일한 PaintMap 계산을 관리 배열로 실행하며 네이티브 텍스처 업로드 자체는 제외합니다.

Unity 배치 실행이 검증 메서드 진입 전에 종료되어 실제 씬 플레이, GPU 표시, Unity Profiler의 CPU·GC·FPS·메모리 수치는 미검증입니다. 실행 시간의 소규모 독립 측정은 실제 게임 FPS를 의미하지 않습니다.

## 메모리 영향

1024 지도에서 제거한 별도 Color32 배열은 8192 × 8192 × 4바이트, 즉 256MiB입니다. 실제 프로세스 최대 메모리 감소량은 측정하지 않았습니다. 먼지 풀과 경로 캐시는 반복 생성 비용을 줄이는 대신 재사용 용량을 해당 지도 또는 유닛 수명 동안 유지합니다.

생존 시간은 공통 시각에서 빼는 방식이 아니라 동일한 프레임 덧셈을 묶음별로 한 번 적용합니다. 따라서 기존 개인 수치의 덧셈 순서를 유지하며 생성 시점·개별 추가 시간·쓰러짐이 다른 개체는 별도 상태로 분리합니다. 영역별 경로 캐시는 최종 경로만 감시하지 않고 막힌 후보와 대각선 모서리의 실제 점유 조회까지 기록합니다.
